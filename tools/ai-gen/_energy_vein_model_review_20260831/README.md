# 当前16格拼接能量矿脉：生图前模型检查

日期：2026-08-31。范围：按用户要求检查当前矿脉模型，有明显模型问题时不进入Dev生图。

## 结论

相机、低矮布局与四邻格组织可以保留，不需要推翻重建。但矿线被建成圆管/接头，以及孤立形态外围碎石被画框截断，是生图前应先处理的结构问题。本轮未生成12步候选，未修改原模型或正式贴图。

## 来源与方法

- 实际读取：`../_energy_vein_directional_20260826/energy_vein_directional_master.blend`。
- 查看已有16帧总览，以及原生1024×512的mask00、03、15渲染；读取建模与运行时选图代码。
- `inspect-model.py`仅打开原blend、读取对象并在内存复用原导出器相机投影计算；不保存blend、不重新渲染、不调用生图服务。
- 原始结果见`model-inspection.json`。此次属于用户指定的离线模型检查，未运行游戏测试、浏览器、构建或已有接缝测试脚本。

## 可以保留的部分

- 实际模型相机为正交30°，模型根旋转44.8°；并非透视镜头误设。
- 存在16个独立连接形态；当前正式帧格128×64，原生渲染1024×512。
- 四向矿线连接位置由`LOCAL_ENDPOINTS`明确登记，运行时按4-bit邻接掩码选帧。此次未验证实际游戏拼接效果，不把静态坐标合同当成运行时验收。
- 矿石整体低矮，没有矿洞入口、支柱或高耸水晶，符合贴地资源的总体身份。

## 生图前问题

1. **矿线呈电缆和连接帽造型。** 实际blend的`EnergyBranch`是有0.028圆截面半径的3D曲线，中心线局部Z约0.240～0.252；`SeamCap`是规整柱体。原生图中管体跨过石面、帽状节点明显。Depth会记录此立体造型，不能要求后续材质精修同时忠实保形又变成天然裂隙。
2. **外围散石在画框边缘被切断。** 按原导出器投影，mask00/03/05/15分别有5/8/6/11个碎石mesh横跨画框边缘。此处数量来自原mesh顶点投影，视觉结论同时有现有原生PNG支持。mask00本来没有任何邻接出口，仍出现切半的外围散石，因此不能把所有切边解释为必要拼接。此问题不意味着矿线端点本身不连通。
3. **石块造型偏规整薄柱。** 当前石体主要是5～8边的缩放圆柱，顶面平行、侧壁整齐，变化主要来自尺寸、平面旋转与颜色。可保留大块体量和位置，但应减少饼状/铺装感，避免把造型问题交给高频材质遮掩。

## 建议的小范围修模

先在独立副本处理一款直线代表形态：把凸起圆管改成嵌入石面的扁平矿带，将接头帽改成同宽的自然矿面过渡；接口处仍严格保留原投影接点及其共同截面。若降低模型Z，必须补偿其屏幕投影而不是直接搬动接点。石块只作适度不规则切面、压低部分高度，保留主要布局。外围随机散石收进导出安全范围，连接处按接口合同处理；不改变相机或缩放整图来迁就散石。
