v03按用户反馈，以现代炮组v02的仓鼠为统一脸型标准，修改投石组、野战炮组两名成员的眼鼻、口鼻部、面颊与毛色分布，保留各级帽服、体型、姿势和器械。现代炮组保留自身面部与手持炮弹尺寸，加粗炮管并同步扩大炮口内径，作视觉口径匹配；不是机械工程口径验证，也不承诺图像编辑实现了像素级不变。旧版未删除。

本次v04参照现有长弓手v04与突击步兵v03母图，保留轻俯视、仓鼠向右侧转的全身姿态，并将器械主轴转到画面侧向。两门炮的炮管按画面水平向右，不再明显朝向镜头；投石机底盘朝右、投射臂的运动平面与画面平行，保留臂本身的待发仰角。先生成现代炮组v04，再把它作为前两档的组合方向参考；铜炮v04仍略下倾，另做v05局部调平。这里借鉴步兵的镜头和身体姿态，不照搬突击步兵待机时下垂的枪口。

投石组v05按后续反馈单独修正：两只仓鼠按同等成年体型绘制，头部、身体与脚线不再形成明显大小差；投石勺臂降低到可装填高度，一名双手持石靠近空勺斗，另一名在侧面操作绞盘。保持向右投射的画面方向、统一脸型和木铁皮革语言；其它两档图片不变。这是装填准备母图，替代投石组v04的高举勺臂待机姿态。

本次只修母图构图。后续动画仍须单独对齐每帧炮口、投石释放点、弹体生成位置及翻转方向；没有修改或证明运行时开火错位已经解决。操作手一部分腿部仍被车轮自然遮挡，动作生成时需注意肢体和器械不融合；静态图不代表已验证机械动作。
