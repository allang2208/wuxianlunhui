# 寒渊棘兽 MiniMax H3 四动作

本任务从六棘身份母图制作待机、重步奔跑、单次咬击与单向死亡。用途档为 `crowd`，正式纹理目标 32MiB、硬上限 64MiB。

结构硬合同为四肢完整且背棘恰好六根：背部五根、肩部一根。第一张移动编辑因只剩五根而被淘汰；正式移动与攻击关键帧均已逐根核对。所有动作朝屏幕右，左向只由运行时水平镜像提供。

四条 H3 源片及正式精灵图已经完成并静态接入。正式奔跑选用 `[f84,f114)` 的单个同足相位周期，共 30 帧、1250ms；f114 是重复端点，不进入图集。正式攻击只取 f68–f96 的第一次完整咬击，共 29 帧、1167ms；f98–f123 的再次张口全部排除。死亡只取 f0–f32 的一次倒地，共 33 帧、1333ms，f32 为首个稳定尸体终帧。

四动作均只进行一次 RIFE 半步插帧，保留源片 24fps 墙钟，不使用动作压缩。正式生产真源为 `sprite-sheet-manifest.json`，预算输入为 `sprite-budget-manifest.json`，直接查看预览位于 `previews/sprites/formal-final/*/`。四张运行时 PNG 位于 `assets/enemies/abyss_rime_beast/`，实际 RGBA 闭包为 25.3516MiB，低于 `crowd` 档 32MiB 目标。

静态核对通过六棘、四足、向右、透明边界、空帧、重复帧与单次攻击/死亡约束；未运行游戏、浏览器、构建或运行时验证。
