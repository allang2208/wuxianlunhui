长墙制作样张没有明显贯穿透明裂口，旧横层与拉伸条带减轻；三款仍是有限纹理，重复和规则块体外形仍可辨认。木铁模型连接现在更清楚，但木纹、断口和整体写实感仍未达到建筑参考图的精修程度。因此**墙门保留候选，不提前替换已接受的正式图**。地板未改；当前地板纹理比墙/小物更强，实机战斗时的主次关系仍需要观察。

所有图是素材制作呈现，不是游戏截图。`room-presentation.png`是人为摆放的美术样张，省略前墙便于看内部，不代表随机生成器、真实密度或房间规划。随机房覆盖与D档配比修复另见`docs/abandoned-mine-random-dungeon-coverage.md`，不由这些图片证明。

## 拼装样张规则修正

- 旧合成器用固定`aabacaa`序列，木撑仅占序列的1/7，与游戏按世界格心散列后在A/B/C三款中选款不一致，会把重复感表现得过轻。当前v3样张改用`_makeWorldBlockPiece`的坐标散列公式，款式顺序直接读取`ISO_WALL_STYLES.abandonedMine.blocks`，不为样张单独稀疏木撑。
- 世界示例原点固定为`(4096,4096)`，与海报排版偏移分离；这不是从真实地图采集的房间。所有墙都保持不镜像，正反两条墙因世界坐标不同可能选出不同序列。
- 墙深度改为相邻半段底线的最大Y加4，门洞内不补墙半段，拐角只保留一个共享块。原合成器统一使用格心Y加4，不能完整表示门端及转角排序。
- 长墙、房间组合图、门淡化GIF共同使用修正后的规则；六段门裁片、落位与既有运动轨迹保持。只重制离线候选样张，未改游戏代码、正式PNG、房间配置或AI请求素材。
- 样张仍不包含游戏光照、角色动态遮挡、真实随机房图和小物散布；有限三款纹理与木撑重复仍须如实保留，不能以人工精选顺序代替正式表现。
