## 制作路径

1. 岩壁：选中的完整Dev绿幕原图，经建筑专用去绿工具剔除背景；只取去除低频光照后的明暗细节。采用固定冷灰石色，避免逐RGB通道提取把绿幕污染变成紫绿条带。
2. 岩体共享：按原相机/投影提取墙面与墙顶周期材质，A/B/C只在材质内部混合变化、边缘共用。重新调用原v3几何脚本，不修改覆盖核心、轮廓、相机、锚点和拼装步长；新石材打包在`mine_visual_v3.blend`。
3. 木铁：门和木撑使用各自48步Dev原图，只在原模型组件mask内回灌RGB，按本地光照包络收敛明暗，边缘无有效AI材质的像素保留本地颜色。木撑原图的暖灰岩石不采用。木铁回灌为确定性贴图处理，不冒称重新建模或AI材质已写入blend。
4. 门：`gate.png`为完整闭合门叶，保留v3模型Alpha。`abandoned_mine_gate.png`为4×4/640px/16帧兼容图集，位移来自游戏现有`leafMotion.liftPixels`。游戏的完整门叶运动读取帧0后独立升降淡化，不依赖图集上缘截断消失；本轮未修改该逻辑。
5. 呈现：固定示例世界原点`(4096,4096)`，按运行时坐标散列选墙、按连接半段最远Y排序；门用现有六段源列裁片。房间图人为摆放小物并省略前墙，仅作美术搭配，不能证明随机生成器、密度或实机遮挡。

初次提取曾出现紫绿条带，已判废并修正去绿与单通道材质提取后重渲；这里的当前PNG是修正版。
