# 紫蚀古树

- 当前阶段：豆包五动作、H3 藤蔓特效、BiRefNet 去背、固定根部标准化、RIFE 2× 插帧、正式精灵表与运行时接入均已完成。
- 正式命名：`紫蚀古树`；内部资源 ID 保持 `purple-blight-ancient`，避免后续重命名路径。
- V1 同时存在风格与可移动双腿结构错误；V2 已修正固定树桩，但仍有过强颗粒、锐化和雕像感，均保留为淘汰稿。
- V3 仅使用正式美杜莎、熊德鲁伊人形/熊形和黑狼作为视觉风格参考，继续保持单一树桩、放射板根、左臂横扫与右手投掷/施法结构，并改用连续中间调与低局部微反差。
- 动作契约：固定树桩、无腿、无移动动画；仅待机、施法、挥手攻击、投掷、死亡。
- 已完成：待机32帧循环；施法、挥手攻击、投掷、死亡各31帧单次动画；全套保持512像素格高和footY=486，空帧/截边/透明脏像素门禁均通过。
- 运行时：固定首领，词条自然/类人形/大型；2.4秒近身扇扫、8秒一秒落地投石AOE并眩晕1.5秒、14秒藤蔓红圈并束缚3秒，缠绕命中后衔接投石。
- 投射物：运行时采用用户在同目录覆盖处理的256×256 RGBA同名岩石，并同步回生成目录保存来源；不再重新抠图。出手锁定0-based第21帧（第20帧仍持石、第21帧已脱手），母版中心点为(269.5, 197)，按左右翻转换算到世界坐标；显示尺寸101px与手中原石比例一致，1秒飞行全程恰好旋转360度。
- 死亡镜头修复：取消逐帧最低碎片贴地，改为首帧固定X/Y源空间锚点；死亡格扩为1024×576、footY=432，在不裁切木材碎片的前提下保留原始坍塌轨迹。
- 组合技收口：挥臂、藤蔓、投石分别按0-based第16/14/21帧精确释放；藤蔓红圈等待与命中后450ms衔接期间锁住普通动作选择，落空或目标失效自动解锁，命中后强制投石并重新进入8秒冷却。
