## 动作关键帧与方向

- 身份/待机/死亡首帧：`references/frostback-musk-ox-idle-keyframe-v01-source.png`。

关键帧由内置 imagegen 以身份锁定编辑模式产生，项目正式副本已保存；提示词执行口径与生成ID见 `manifest.json`。H3 原片必须逐帧确认只含单次攻击、原始墙钟、完整角尖和四蹄，不允许把重复动作或长静止段压缩入正式图集。

- 四段 H3 源视频均为 1024×576、124 帧、24fps，并保留本地 MP4、接触表、GIF 与生成溯源 JSON。
