# Computing Center icon prompts

Runtime contract: upgrade icons are 256x256 RGBA cold-steel four-rivet square badges with a 244px visible frame. Technology icons are 1024x1024 RGBA cold-steel hexagonal badges with a 1000px visible frame. No text; Emoji remains the load-failure fallback.

- `computing-cluster-output`: three attached server racks joined by gold-orange data buses into one expanding compute cluster.
- `computing-population-model`: hamster settlement and house nodes feeding a central gold processor through cyan data lines.
- `computing-power-efficiency`: processor in a closed liquid-cooling loop with two coolant reservoirs and an efficiency gauge.
- `computing-staff`: hamster data-center engineer at a console with four additional operator seats.
- `distributed_computing`: central processor connected to four smaller server-node processors in one hexagonal network.
- `computing_standardization`: processor in a precision calibration cradle with four symmetric diagnostic probes and gauges.

The upgrade prompts used `grand-mall-showcase.png` as the square badge reference. The technology prompts used `mint_standardization.png` as the hexagonal badge reference. Generated checker/black backgrounds are removed with deterministic geometry masks in `finalize_icons.py`.
