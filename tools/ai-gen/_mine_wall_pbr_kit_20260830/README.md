# 矿洞岩壁 A/B/C 共享材质候选 · 2026-08-30

本目录是独立制作候选，`runtimeInstalled:false`。正式墙 PNG、旧门、地图、占格、碰撞和预载配置均未替换。

## 本轮内容

- A：连续开凿岩面。去掉旧A逐格木撑/碎石顶冠，保留不露底的实体核心。
- B：复用A岩体，仅增加内部稀疏矿脉，没有自发光。
- C：复用A岩体，增加局部木柱、横梁、斜撑与克制铁箍；不是每块墙都使用木撑。
- 第二次建模将四面位移岩层的端点延伸至相邻面的位移边缘，封住原来露出核心材质的细竖带。混排样张中的逐格竖痕明显减弱，不靠运行时填缝贴片或改铺设距离处理。

## 管线与来源

1. 复用 `../build-mine-wall-a-rockface.py` 的连续岩体、几何尺寸、相机和原生石面粗糙度。
2. 内置 ImageGen 新生成**平面岩石底色**，完整提示词见 `slate-albedo-prompt.txt`。原始生成文件路径、实际尺寸1254×1254见 `manifest.json`；未宣称使用了FLUX/Klein或Depth生成。原始图保留，目录内为制作副本。
3. `../build-mine-wall-pbr-kit.py` 将该图作为共享材质的 Base Color，和中性底色混合。细微凹凸仍用原生程序纹理；AI不生成墙图、不改几何、相机、阴影、Alpha或Depth。
4. 材质在shader内以实际铺设周期镜像重复，不假定原始AI图的对边像素已经无缝。镜像采样保证周期边界采样连续，但仍可能看出重复或镜像纹理。
5. Blender统一渲染A/B/C的1024px透明PNG及16bit Raw Body Depth。`.blend`内包含三组可编辑模型和打包底色图，默认只显示A组。
6. `../compose-mine-wall-pbr-kit.py` 导出Alpha和离线拼装样张。样张是资产制作结果，不是游戏截图或运行时验证。

## 接缝合同

- 核心2.12×2.12×3.04、原地脚锚点、1024×1024画布、260×259显示、128×64占地不变。
- 相机 `(10,-10,9.645)` 指向 `(0,0,1.48)`，正交尺度5.25；共用中性平行主/辅光。
- 两个方向固定步长 `(+64,+32)` / `(-64,+32)`，材质和岩层周期为对应的模型距离1.8275990652，不用较宽的2.12核心宽度作周期。
- 转角使用同一格去重；A/B/C复用同一岩体、UV、材质和顶冠，不随机翻转、位移或缩放。
- 旧矿洞门仅作六格跨度接口参照；离线显示关闭0帧和开启15帧、沿用六层排序，**没有重做门或验收所有方向**。旧15帧原素材上部已有裁边，本轮没有修门图。

## 仍未解决的范围

- 岩层有规则重复，长距离仍能识别同款纹样；B/C只是局部打断，不代表完全消除重复感。
- 旧门仍偏暖棕色，与新C木撑并未统一材质。正式整套接入前需要处理这一差异，不能只换A造成新旧混搭。
- 游戏缩放、透视遮挡、门全部方向与16帧开合仍需用户测试。本轮没有运行测试、构建或运行时验证。

## 重新制作

在仓库根目录以Blender后台运行 `tools/ai-gen/build-mine-wall-pbr-kit.py`，再用带Pillow的Python运行 `tools/ai-gen/compose-mine-wall-pbr-kit.py`。仅生成本目录候选，不安装到游戏。依赖的基础建模和旧门拼装辅助脚本均通过显式文件路径引用。
