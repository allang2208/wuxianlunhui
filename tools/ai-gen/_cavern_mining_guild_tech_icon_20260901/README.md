# Cavern Mining Guild technology icon

This task contains the selected built-in ImageGen raw, the exact prompt, and the deterministic technology-badge finalizer. The finalizer reuses the shared cold-steel hexagon geometry, removes the generated RGB black exterior with a feathered geometry mask, normalizes the visible badge to 1000px on a 1024px RGBA canvas, and writes the production icon plus a multi-size preview.

Runtime target: `assets/ui/technology-icons/cavern_mining_guild.png`.

No game, browser, build, or automated test was run. Runtime acceptance remains with the user.
