# 矿洞 A 墙整图精修试作（2026-08-30）

本轮确实进行了整块墙面的 AI 图像编辑，使用内置 imagegen；不是重新生成一张平面底色，也不是 Blender 重渲。但这批没有达到正式墙贴图的要求，全部保持候选/废案状态，未接入。

## 结果

- `wall_a_pass1.png`：岩面细节更清楚，带真实Alpha；但添加了顶部边条和底部凸缘，轮廓也有漂移，不适合直接用于连续拼墙。
- `wall_a_pass2.png`：收掉多余边条后的材质试作。实际为RGB，棋盘格已烘进背景；轮廓、纹理密度仍不达标，只可看材质方向。
- `wall_a_cutout_attempt.png`：尝试仅去棋盘背景，但仍输出RGB且改变了墙面明暗，判为失败，不继续重复抽图。

三张都是1254×1254，并未遵守请求的1024×1024。没有为了入库强行缩放或调整锚点。

## 来源与约束

- 编辑真源：`../_mine_wall_pbr_kit_v2_20260830/wall_a.png`。
- 配对Body Depth只作为参考图输入；这次没有使用ControlNet，也没有确定性回填原Alpha，因此不宣称“Depth硬锁结构”。
- 建筑风格参考：`../../../assets/terrain/blacksmith_lv3.png`；材质方向参照共享v5规范，墙不新增建筑地台或构件。
- 三次完整提示词分别在`prompt.txt`、`prompt_pass2.txt`、`prompt_cutout.txt`；直接输入顺序、原始生成路径和结果状态记录在`manifest.json`。
- 原可编辑Blender、Alpha、灯光和门轨迹仍以v2目录为准，没有改动。

## 后续边界

不把这批复制给B/C和门，也不将这些图替换到`assets/terrain`。正式版本仍需走原模型Depth约束，并用原Alpha、同源低频光照和拼接边界完成确定性收口，再输出按实际锚点铺设的双轴长墙及墙门组合。
