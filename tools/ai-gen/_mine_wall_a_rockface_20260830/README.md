# 矿洞 A 款岩壁：接缝基模与原生 PBR 候选

本批是 2026-08-30 用户确认方案后制作的 A 款基准，不是正式替换。`runtimeInstalled:false`。
没有改动 `assets/terrain`、BootScene、墙体配置、碰撞、地图布局或门动画。B/C 和旧门仍是原版本。

## 本轮内容

- 用连续岩面替换独立堆石与每格木撑；去掉散石顶冠和外凸底座，墙脚并入岩面。
- 独立、可重建的 Blender 模型；内部实体核心仍为 2.12×2.12×3.04。
- 岩面有四层不等距的开凿裂隙、稀疏斜裂纹；底材为低饱和冷灰石面，克制颗粒和高光。
- 原生 PBR 材质直接渲染；**本轮没有提交 AI 生成，没有把模型候选称为最终写实精修成品**。
- 固定原相机、1024²、groundCenter=(512,761.9959)、display=260×259、footprint=128×64、wallH=132、halfThick=13。
- 16bit Raw Body Depth 与模型图使用同一相机，Alpha 从原生 RGBA 导出。`.blend` 保存的是校准后的材质场景，不是临时 Depth 场景。

## 接缝处理

第一版的实体覆盖没有露底，但按模型边界收平的岩面带，在逐格拼装中留下了竖向接痕。
现版把岩面和程序材质的水平周期改为实际 64px 横向铺设步长所对应的模型距离：

`period = 64 × 5.25 × sqrt(2) / 260 ≈ 1.8276`

这与 2.12 的实体宽度不同：实体宽度负责交叠覆盖，纹理周期负责连续。保持共同顶沿，去掉每格侧边的宽平带。
同一组中性平行主/辅光减少每块重复出现的距离衰减渐变，禁止镜像翻转光向。没有通过随机拉伸、偏移、旋转、
在场景加填缝贴片或重画地板掩盖接缝。

`wall-a-seam-assembly.png` 是离线素材拼装：两轴各8格连续墙、双臂共享转角、四角共享闭合房间、
墙—旧门—墙的0/15帧参照。墙按脚点Y+4排序，旧门按原gateX分6层、每层底端Y+3.9排序。
离线墙段和转角目视未见露底缺口，逐格接痕较第一版减弱；这**不代表**游戏中任意缩放、全部门方向、
动态遮挡与角色透视已通过验收。旧门源和高位门帧的裁切情况没有在本轮修复或重新验收。

复用现有墙套件的相机/Depth辅助函数和离线墙门拼装数学，不写回旧源。

## 后续边界

当前 A 款岩层仍较规整，长距离同款重复可见；半写实材质表现尚需再深化，不能据此宣布整套矿洞墙已统一。
后续如进行 Depth 受控材质精修，必须保留本模型和 Alpha，且重新检查材质周期：Depth 约束不能保证 RGB 无缝，
逐张自由重绘会重新引入色差和拼接缝。优先将表面材质回到共享模型/周期贴图中，再同灯组渲染。
B/C 应复用此核心和接合轮廓，仅在内部增加稀疏矿脉或木撑，不能重新随机生成墙脚、顶沿和接合带。
整套齐备后再依据用户选择晋级；旧门若需同步材质，仍保留原独立门叶、六格跨度和16帧运动。

未运行测试或运行时验证，按约定由用户测试；本轮仅做资产制作与离线素材查看。
