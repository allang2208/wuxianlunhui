# 矿业专家移动方向对照

用户指出移动方向与现有军事单位不一致，本轮只对照现有正式素材与当前候选，未重新生成视频、修改运行时或运行测试。

`military-vs-mining-expert-direction.png` 展示仓鼠特战、重机枪、火枪、普通矿工与当前矿业专家的三个步态阶段；`direction-motion-comparison.gif` 以24fps对照当前矿业专家、重机枪和火枪，后两者按配置循环。每个单位使用一个固定裁框和等比展示倍率，仅方便观察方向，不代表游戏实际体量。来源、配置路径和帧号见 `sources.json`。

## 结论

- 当前矿业专家的胸口、骨盆和迈步轴线更朝向镜头，虽脸和电钻偏右，整体仍有向观众走的感觉；空载与负重共用同类构图，两个移动都需要改方向。
- 重机枪与火枪的身体侧面、前后脚错位和向右推进更清楚。特战本身也比较正面，不能把任意军事单位都当作一致标准。
- 推荐以重机枪作为主要朝向参考：同为双手持重型工具、上肢受限且背部有负重。火枪仅辅助确认侧向推进，不复制其冲跑姿势或速度。普通矿工另提供工人体型的交叉参考。
- 上一轮提示词明确保留母图的three-quarter orientation，且要求胸/胯继续保持参考方向；参考母图是偏正面的展示站姿，因而把不合适的移动基准锁进了视频。不能仅靠翻转、旋转整图、改播放速度或插帧修复透视关系。

## 建议改法

保持角色脸型、铜盔、工作服、电钻、紫晶背包和体型，先制作同角色的右向移动关键帧：鼻尖、胸腔、骨盆、膝盖及脚尖共同朝右，露少量胸前并保留轻微俯视；腿沿画面左右方向交替迈步，避免向镜头踢出脚底。以重机枪的实际移动帧作视角参考，而不是把军事单位当身份图直接送H3。

空载和负重共用这个相机、体型与朝向，只在负重图中保留背包并适当增加前倾。关键帧应处于明确迈步阶段，确认后再经MiniMax生成两个移动循环，可减少当前站姿首尾造成的末段停步。挖矿暂保留，不扩展重做；正式抠图、RIFE与游戏接入仍未批准。

项目知识库 `skill/02-ai-asset-pipeline.md` 的“侧向跑动必须给动作方向参考”指出同类风险；本轮结合实际H3输出确认问题，而不是直接把其他模型的历史结论当证据。
