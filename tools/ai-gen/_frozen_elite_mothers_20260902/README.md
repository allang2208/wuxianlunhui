## 统一母图合同

- 近正交、轻微俯视的低三分之四或侧面主导镜头，严格面向屏幕右侧。
- 完整单体、白底、动画友好的静态中立姿势，肢体、脚底、尾巴和装备均有安全留边。
- 维持普通原型的物种/阵营/装备锚点，精英差异来自真实轮廓和材质变化，不靠背景、光环或粒子。
- 怪物默认写实低饱和 PBR；精英复杂度高于普通怪但低于首领，不堆叠首领级皇冠、巨型法器或环境特效。
- `futurePlanOnly=false`、`runtimeIntegrationActive=true`；正式接入已完成静态收口，未运行游戏、构建或浏览器探针。
