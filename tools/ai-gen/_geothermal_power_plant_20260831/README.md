## 外形设计

- 与光伏电站同档的4×4能源建筑。复用其900×720×20模型地台尺寸、低矮混凝土地面与30°正交相机；模型底座尺寸不等于最终逻辑格尺寸，定稿入库时另作512×256视觉占地标定。
- 前部一对密封井口：暖棕色采热井、灰青色回灌井，各有法兰、螺栓、阀轮、压力表和低护栏；表达从地下取热并循环回灌，不使用裸露熔岩或燃烧炉口。
- 左侧单台卧式换热器，右侧一组同轴涡轮和发电机；设备有落地支脚与共用机座，管道直接相连，不出现悬浮机件。
- 后侧一栋低矮单层控制机房，真实凹入门洞、独立开启门扇、玻璃控制窗、配电柜和无文字三道热浪徽记。
- 屋顶两组附着式冷凝风机壳与固定格栅，采用闭式管路；不生成高烟囱、冷却塔、光伏板、人物或车辆。
- 冷灰混凝土、灰绿机械外壳、暗钢、少量旧黄铜，以及暖供水/冷回灌两种管色。当前为材质分区建模预览，不是AI精修成品。

## 用户要求：后续接入，不属于本轮已完成功能

1. 地热科技与光伏科技平级，不做成光伏的下一级。光伏当前为四级能源科技，前置为风力发电与四级住房；地热拟从相同前置并列分出。
2. 相同升级、岗位、转换效率和中性环境下，地热产能为光伏的85%。当前光伏基础原始产能为600/4秒，拟定地热为510/4秒；如沿用90%基础转换效率，100%岗位效率下为459/4秒，对照光伏540/4秒。实际初始岗位为3、每人20%，不得将100%效率参考值误报为新建建筑实际产能。
3. 地热允许在地牢、矿洞等无天然阳光位面建造。没有用户指定的“必须覆盖矿脉/随机热斑”附加门槛；井口是建筑模型的一部分，不擅自增加选址资源要求。
4. 光伏新增“位面有天然阳光”的建造资格；普通昼夜不是此资格判定，地表入夜不能被当作无阳光位面。既有光伏建筑的处理留到接入时明确，不在本轮拆除或更改旧档。
5. 需要正式接入时统一处理科技、建造资格、产能/升级、前后台结算、存档和详情提示；本轮不放入不可用科技或占位建造按钮。
