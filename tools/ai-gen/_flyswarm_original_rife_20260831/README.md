# 苍蝇群：原图插帧与尺寸调整（2026-08-31）

按用户最新要求，停止 H3 重制，继续使用游戏原有苍蝇群。H3 候选没有接入运行时；本目录不引用候选母图或视频。

## 动画与素材

- 原图：`assets/enemies/flyswarm/idle.png`，512×512 单帧、8×4 布局、32 帧、16 FPS。原文件不覆盖，清理后直接作为唯一未插帧输入；重复制作副本已移入可恢复清理区。本次来源为现有精灵图，没有对应的新源视频。
- 正式图：`assets/enemies/flyswarm/idle-rife64.png`，512×512 单帧、8×8 布局、64 帧、32 FPS；待机和移动仍共用 `enemy_flyswarm_idle`。
- 每轮仍为 2 秒。RIFE v4.6 在相邻原帧间插入一帧，包括原第 31 帧到第 0 帧的循环衔接；原关键帧位于输出偶数索引。
- 源缩放为 1；不重新绘制、不逐帧缩放或居中、不做脚底对齐。保留原来的悬浮升降、颜色及半透明翅膀。插帧工具清零全透明像素的 RGB，原帧可见像素不重采样。
- 原图已有的蓝色边缘没有额外清理；这是用户选择的原美术。细小虫翼的插帧观感仍待用户在游戏中确认。
- 生产使用的 RIFE v4.6 RGBA v8 精确半步工具保存在 `rife-production-snapshot.py`；远端通用入口当时仍为 v3，不能用旧算法冒充本次可复现版本，也不夹带其他会话的通用工具改动。

## 世界尺寸与判定

所有下列长度按原值 ×1.2；这是长宽/半径放大 20%，不是面积只增加 20%。不改变实体逻辑坐标。

| 配置 | 原值 | 新值 |
|---|---:|---:|
| `size` | 32 | 38.4 |
| `render.spriteSize` | 120 | 144 |
| `collisionRadius` | 45 | 54 |
| `render.collisionWidth / collisionHeight` | 78 / 100 | 93.6 / 120 |
| `render.projectileHitbox.width / height` | 78 / 100 | 93.6 / 120 |
| `render.footOffsetY` | 30 | 36 |
| `render.colliderOffsetY` | 20 | 24 |

三块接触伤害区的中心和半径也同步缩放：`(0,25,34)` → `(0,30,40.8)`，`(-26,29,22)` → `(-31.2,34.8,26.4)`，`(26,29,22)` → `(31.2,34.8,26.4)`。地面椭圆仍使用原来的 2:1 透视。

`Collider` 的实际高度从 `render.spriteSize` 推导，因此由 120 变为 144；地面半径由 45 变为 54。源画布上的逻辑根点仍为 `(256,384)`，不将飞行角色锁到逐帧脚线。

保留 `noCollision: true`、穿过其他单位的原有行为、墙体处理、速度 200、伤害倍率与 500ms 基础接触伤害间隔。通用近战保持禁用；实际接触范围会随这次体积一起增大。

## 预算与文件

用途档位 `crowd`。单张正式图为 4096×4096，基础 RGBA 占用 **64 MiB**（原图 4096×2048、32 MiB）；没有苍蝇群自身必须加载的伴生资源。待机与移动共享纹理，只计一次；原图备份不在 Boot 加载清单中。

本次超过 32 MiB 目标、未超过 64 MiB 准入线。为保留原图原生关键帧，不降低源分辨率；原源 Alpha 联合集接近完整 512 格，单靠裁边不能回到 32 MiB。未调整全局纹理预算。同场怪物组合与切场过渡仍共用项目 512 MiB 稳态目标 / 640 MiB 过渡预算，本次未进行场景预算验证或性能测量。

- `manifest.json`：来源、帧布局、动作时钟和接入状态。
- `sprite-budget-manifest.json`：单纹理清单；未运行独立预算检查器。
- `reports/rife.json`：制作工具随产物写出的插帧记录，不代表游戏验收。
- `previews/flyswarm-rife64-2s.gif`：正式动作时钟的预览。
- `previews/flyswarm-before-after-2s.gif`：原版与插帧/放大后的对照；制作示意放大 2 倍，黄色圈表示接触区，不是游戏截图或完整受击体。
- `previews/review-all64.png` 与 `reports/review.json`：用户要求复核后的全帧联系图和离线素材/配置证据。工具默认时钟预览已移出活动目录；重建临时文件放入忽略的 `_build/`。
- `reports/cleanup.json`：逐文件可恢复清理清单；H3候选仅保留历史元数据/提示词，僵尸犬获准v04及正式四动作来源不动。

涉及运行时文件：`data/enemy-config.json`、`public/data/enemy-config.json`（仅 `flySwarm` 节点），`src/phaser/scenes/BootScene.js`（读取贴图/帧数/帧率），`src/entities/enemy-types/fly-swarm.js`（尺寸回退值、注释），以及正式精灵图。

## 重建与验收边界

在项目根目录用带 Pillow、NumPy、SciPy 的 Python 执行 `tools/ai-gen/_flyswarm_original_rife_20260831/build.py` 可重建；加 `--install` 才复制正式图，`--reuse-generated --install` 可安装已有临时产物或确认现有正式图。`--rife <exe路径>`可指定RIFE v4.6工具；默认路径沿用本地生产环境，不下载模型。脚本不修改业务配置。正式输出仅保留运行时PNG，重复成品不入库。
