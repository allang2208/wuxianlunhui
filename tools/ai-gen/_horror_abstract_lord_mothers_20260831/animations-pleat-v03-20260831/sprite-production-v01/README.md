已查看固定根点对照、攻击/蠕行/收拢联系图及源片循环候选。输出保留材质和闭合攻击，背景、离体平台角标与地面投影通过BiRefNet主体抠底去除。制作统计为：274个有效帧、无空帧、无触边，Alpha距边至少4px；透明RGB为0，原关键帧保留，RIFE未报告黑块/红色异常或冻结源帧兜底。

这些统计不是动态观感或游戏验收。蠕行源动作有明显前端张合，末首像素差约为平均相邻差的1.95倍，仍需看GIF确认接缝；不通过逐帧挪动掩盖原片差异。攻击仍是偏慢的原片节拍，收拢幅度偏轻，个别源帧的轻微色边保留，没有借插帧重绘已认可源片。

animation-parameters.json已记录正式纹理映射，但仍不是游戏自动读取的配置；运行时真源在双份enemy-config.json。世界缩放为1（源到世界0.35），Collider半径90/高130，攻击固定根点朝前200×96，第26帧/1625ms一次命中，第28帧/1750ms起进入收势易伤。早期第34帧仅是制作阶段暂定姿态，已被实际推出帧取代。Boot与自动实体工厂已登记；空腔之卵另行完成五动作接入。

## 重建
