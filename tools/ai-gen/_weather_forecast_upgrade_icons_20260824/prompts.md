# Weather Forecast Tower upgrade icon prompt set

Shared style: 256x256 cold-gunmetal square badge, exactly four corner rivets, dark faceted recessed field, slate-blue shadows, aged-brass instruments and restrained sky-blue observation light. The subject must remain readable at runtime size; no text. Outside the frame is transparent.

- `weather-forecast-horizon`: brass long-range telescope over three forecast arcs carrying light-rain, heavy-rain and thunderstorm medallions.
- `weather-forecast-cycles`: mechanical weather computation engine, three pressure gauges, plotted observation curve and blank research ledger.
- `weather-forecast-duration`: numberless chronometer with a rain-cloud start node, clearing-sun end node and bounded duration arc.
- `weather-forecast-storm-warning`: armored warning beacon detecting an ochre sandstorm vortex and a blue-green spectral fog event.

The raw images were generated with the built-in ImageGen workflow. `finalize_icons.py` finds the visible badge bounds, applies the standard eight-sided corner-cut mask, removes painted black/checker canvases and installs 256x256 RGBA runtime assets.
