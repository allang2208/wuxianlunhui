# 2026-08-27 霰弹枪首批开发来源记录

## 交付清单

- `weapon39` / S686 / 普通：双发折管、高单发爆发、长整枪换弹。
- `weapon40` / M870 短管型 / 普通：泵动逐发装填、短射程、高击退。
- `weapon41` / KSG-12 / 优质：牛尾式双管仓、12 发容量、紧凑持续火力。
- `weapon42` / SPAS-12 / 优质：较慢射速、紧散布、重控制。

最初考虑 Benelli M4；核对现有史诗 `Super90` 后发现二者同属 M4 Super 90 系谱，因此在正式接入前改为 KSG-12，避免品质线重复。

## 图像生成模式

- 工具：Codex 内置 ImageGen。
- 模式：每把枪独立生成一张生产级透明侧视主图并保存到 `assets/weapons/`；最初复制到 `assets/icons/` 的水平重复图已在斜向物品图落地后清理。
- 共同约束：单一完整武器、枪托朝左/枪口朝右、严格水平纯侧视、真实透明 alpha、无人物/手/弹药/文字/边框/底座/投影、完整枪体留安全边距。
- S686 结构提示：上下叠置双管、折管机匣、双扳机、深色胡桃木、发蓝钢。
- M870 短管型结构提示：14 英寸破门枪管、管式弹仓、肋纹泵动护木、磷化钢与木质手枪握把。
- KSG-12 结构提示：牛尾式机匣、双管式弹仓、全长导轨、紧凑泵动护木、黑色聚合物与橄榄绿面板。
- SPAS-12 结构提示：开槽散热罩、粗大泵动护木、管式弹仓、钩形折叠托、炭黑钢与聚合物。
