# 两把传说手枪设计候选（2026-08-28）

> 状态：用户已确认视觉方向；两把武器、专属机制、三槽六件改造与正式运行时资产均已接入。

## 共同边界

- 预留编号：`weapon54` / `weapon55`。
- 稀有度、等级、售价：`legendary` / 21级 / 3200。
- 枪族继续使用 `weaponType: pistol`，保持可双持、主副手实例状态隔离，并被防御塔白名单排除。
- 所有基础伤害只走 `attackFormula`；传说机制使用实际出弹或未被弹反的首次有效命中回调，不建立第二套基础公式。
- 强度以敏捷、精神各50点的 `+0/+10` 为统一比较口径；传说的优势来自满足条件后的输出形态，不无条件覆盖神话手炮。

## weapon54：赤冕清算

### 定位与外观

- 定位：首领/精英单点，奖励持续锁定同一目标的慢射重手炮。
- 视觉：黑钨钢、深红珐琅、旧黄铜锁桥；机匣上三枚判决刻度对应三次确认命中。顶部使用带中央红色准星槽的低矮三段裁决脊，不再采用直白皇冠轮廓；现代哥特重手炮不使用左轮弹巢，也不重复猎隼的西部木握造型。
- 当前正式候选：`candidates/crimson-crown-settlement-v02.png`；未采用的早期候选不进入归档。

### 基础数据

- 弹匣7发，换弹1450ms，攻击间隔380ms。
- 射程1160，弹速1520，击退11，半自动。
- 公式：`17 + 敏捷×0.83 + 精神×0.83 + 强化×(2.10 + 敏捷×0.16 + 精神×0.16)`。
- 散布：起始2发、最大6发、620ms恢复、最大10°。

### 传说机制：血债终审

- 在1800ms内连续三次有效命中同一目标时，第三次命中追加一次相当于该发基础伤害75%的“终审”物理伤害；追加伤害不再次推进终审。
- 切换目标时，旧目标计数立即清除，新目标从1开始；超时也清除。
- 只有实际命中且未被盾牌弹反才推进；主副手按各自装备实例独立记录。
- 第三发本身若已击杀目标，则本轮清算结束，不把终审伤害迁移到其他目标。

### 三槽六件专属改造

1. 血债机括（二选一）
   - **双联法槌**：所需命中3→2，终审倍率0.75→0.35，基础伤害-5%；更易触发但压低上限。
   - **四阶终审**：所需命中3→4，终审倍率0.75→1.25，窗口+450ms，攻击间隔+45ms；延后清算换取重爆发。
2. 清算弹（二选一）
   - **连坐碎誓弹**：终审倍率-0.15，并对120px内最多3个其他目标造成该发28%伤害；把单点预算换成小范围连坐。
   - **斩首红契弹**：目标生命低于30%时终审倍率额外+0.45，但射程-140、弹速-12%；强化收尾，牺牲远距手感。
3. 王座握柄（二选一）
   - **不移王座握**：锁定窗口+700ms，移动速度-8%、攻击间隔+25ms；容错更高但转场迟缓。
   - **篡位速断握**：攻击间隔-70ms、伤害-10%、锁定窗口-300ms；更快完成三连，但更怕失误。

## weapon55：万象回廊

### 定位与外观

- 定位：多目标转火，奖励主动在敌群中切换目标的高速半自动手枪。
- 视觉：珍珠银钛、午夜青结构框、蓝紫棱晶；三条独立导光管从握把上方出发，在枪口前汇成一线，直接表达“三目标闭环”。
- 候选：`candidates/myriad-corridor-v01.png`。

### 基础数据

- 弹匣12发，换弹1550ms，攻击间隔290ms。
- 射程1080，弹速1700，击退3，半自动。
- 公式：`14 + 敏捷×0.65 + 精神×0.65 + 强化×(1.70 + 敏捷×0.12 + 精神×0.12)`。
- 散布：起始2发、最大8发、390ms恢复、最大6°。

### 传说机制：三象闭环

- 在2400ms内依次有效命中三个不同目标后立即闭合回路，对这三个已命中目标各追加一次相当于该发基础伤害25%的“回廊回响”；追加伤害不重新登记目标。
- 重复命中已登记目标不会推进计数；超时清空整个目标集合。闭环结算后重新开始收集。
- 只有实际命中且未被盾牌弹反才登记；目标死亡后仍可参与本次闭环计数，但回响不会对已死亡目标转移或补偿。
- 主副手按各自装备实例独立记录，避免双持共享三目标进度。

### 三槽六件专属改造

1. 导路棱镜（二选一）
   - **双棱捷径**：所需目标3→2，每目标回响0.25→0.14，弹匣-2；闭环更频繁但总回响更低。
   - **四象展开**：所需目标3→4，每目标回响0.25→0.36，窗口+500ms、攻击间隔+35ms；要求更大敌群换取高总量。
2. 回响晶芯（二选一）
   - **折返焦镜**：闭环只对最后命中的目标回响一次，倍率提高到0.90，射程-100；把三目标准备转化为单点折返爆发。
   - **并行散射棱**：已登记目标回响降至0.20，并额外选择最多2个附近未登记目标各造成0.20回响；扩大清群面，削弱原三目标结算。
3. 游廊握柄（二选一）
   - **长廊记忆握**：闭环窗口+900ms，换弹+320ms、移动速度-7%；转火容错更高，续航和走位变差。
   - **瞬映游击握**：攻击间隔-50ms、每目标回响-0.07、弹匣-3，移动速度+6%；强化高速换靶，但降低每轮回路收益。

## 候选生成方式

- 使用 Codex 内置 ImageGen，要求真透明背景、右向水平侧视、单一完整手枪、无人物/文字/水印/投影。
- 赤冕提示核心：`obsidian tungsten + crimson enamel + aged brass low-profile locking bridge + three judgment notches`。
- 万象提示核心：`pearl titanium + midnight teal frame + three embedded cyan conduits converging before the muzzle`。
- 正式接入使用用户确认的水平侧视造型：按恒星圣谕基准归一为2048²持有源（枪体宽1764px，中心0.487/0.524），装备栏/背包/掉落图为512²同造型透明图；Phaser持有贴图压为512²，UI运行时图标压为128²。
- 12枚专属改造件均由Codex内置ImageGen逐件生成真透明RGBA源，正式512²图位于`assets/icons/craft-legendary-pistols/`，128²运行时副本位于`assets/ui/runtime-icons/icons/craft-legendary-pistols/`；源图和总览保存在本任务的`generated/`与`previews/`目录。
- 正式归一化入口为`build-formal-assets.py`，只读取仓库内候选与`generated/mods`来源，不依赖Codex外部缓存；七把手枪的统一运行时压缩入口为相邻普通手枪任务目录的`build-runtime-pistol-assets.py`，PNG使用`optimize + compress_level=9`。

### 赤冕 v02 局部修改

- 使用 Codex 内置 ImageGen，以早期构图为编辑目标；仅移除顶部皇冠形瞄具，替换为“低矮黄铜/黑钢锁桥 + 中央红色准星槽 + 两侧短翼”，明确禁止皇冠、王冠、角、瞄准镜及枪身其他变化。
- 内置工具返回了烘焙浅灰棋盘格的RGB图；使用项目既有`strip-checkerboard-alpha.py`只清除两种浅灰背景并保留最大主体，正式候选为1254² RGBA真透明图。棋盘格中间图与未采用候选已在交付前清理。
