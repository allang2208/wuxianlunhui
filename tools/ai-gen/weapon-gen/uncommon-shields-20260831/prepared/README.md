## 尺寸和绑定约定

- PNG保留生成器的原始清晰度，未重采样。44px背包格、64px装备槽是预览显示尺寸；并非声称已经导出了44/64px PNG。
- 正式运行资源若需要128px图标和512px手持图，应在正式接入时另行导出。缩放必须等比，并同步转换握点，不能只改图片尺寸。
- 参考角色身高144px：拳盾可见高度48.96px、卫戍盾82.08px，现有小圆盾60.48px。尺寸只改变显示，不改格挡角度、碰撞或伤害。
- 可见边界为Alpha≥128的范围，数组为左、上、右开、下开，单位是母图像素。预览按此范围等比适配，保留盾尖。
- 拳盾握点候选 `(669,795)`：中央盾脐后方短握柄的投影；卫戍盾候选 `(286,352)`：背面上侧承带内的握持位置。它们是人工图内标定，**不是骨骼自动检测或已通过实机确认的精确绑定**。
- 缩放比例 `s = 目标可见盾高 / (可见下边界 - 可见上边界)`。若后续裁切、补边或缩放，握点也必须应用相同变换。玩家手掌的世界点保持由副手骨链提供。
- 两款需单独的纹理键与握点配置，不得复用旧小圆盾的全局origin。右向/左向、待机/举盾的遮挡和翻转关系必须在正式接入后确认。
