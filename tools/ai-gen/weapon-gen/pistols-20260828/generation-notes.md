- 使用 Codex 内置 ImageGen 生成，现有 `assets/weapons/beretta93r.png` 只承担项目写实材质、光照和构图风格参考，不复用枪型。
- M1911A1 持有图约束：军用经典轮廓、深色烤蓝钢、棕色防滑木握把、外露击锤、严格左侧正投影。
- USP .45 持有图约束：全尺寸 .45 比例、钢制套筒、黑色聚合物底把、方形扳机护圈、外露击锤与保险/待击解脱杆。
- Five-seveN 持有图约束：细长阶梯式套筒护罩、后部防滑纹、聚合物底把、长握把、附件导轨与20发弹匣比例。
- 物品图逐把以自身正式侧视源为唯一身份参考，只改变为枪口朝右上的三分之四视角，不跨枪复用。

## 透明与归一处理

ImageGen 输出为烘焙浅色棋盘格 RGB，未直接入库。使用
`tools/ai-gen/strip-checkerboard-alpha.py` 识别两种背景色、保留最大主体、去除边缘污染并生成真透明 RGBA。

持有源统一到手枪基准：2048²、Alpha 内容宽约 0.862、内容中心约 `(0.487, 0.524)`；最长边512px运行时副本写入
`assets/weapons/runtime/weapons/`。物品图统一到512²、28px安全边距。

## 伤害公式与同级基准

伤害继续只由 `attackFormula` / `computeWeaponAttack` 结算：

- M1911A1：`7 + 敏捷×0.35 + 精神×0.30 + 强化等级×(0.45 + 敏捷×0.05 + 精神×0.04)`。
- USP .45：`9 + 敏捷×0.55 + 精神×0.45 + 强化等级×(0.75 + 敏捷×0.13 + 精神×0.13)`；射击间隔由330ms调整为300ms。
- FN Five-seveN：`6 + 敏捷×0.55 + 精神×0.25 + 强化等级×(0.50 + 敏捷×0.06 + 精神×0.04)`。

按敏捷/精神各10点、整匣射击时间加换弹时间计算：USP +0/+10持续输出约46.53/128.57，对应Beretta 93R约45.96/128.94；Five-seveN约43.75/90.63，对应G18约42.11/91.23。M1911A1约21.53/43.05，承担普通稀有度慢射重弹基线。
