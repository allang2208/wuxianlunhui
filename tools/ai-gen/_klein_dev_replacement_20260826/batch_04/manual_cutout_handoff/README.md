# 第四组人工抠图交接

统一要求：

- 画布、主体位置和尺寸保持 `1024 x 1024`，不要裁剪、缩放或移动。
- 只处理背景、外部投影和边缘残色，不重画建筑，不修改主体结构。
- 输出透明 PNG，文件名统一保存为各自目录中的 `manual_body.png`。
- 不保留建筑之外的外投影；建筑自身内部的明暗、AO 和接触关系保留。

## 01_computing_center

- 输入：`source_raw.png`。
- `auto_body_reference.png` 只用于参考自动锚点和当前轮廓，不能直接作为成品。
- 删除：所有绿色幕布、建筑右侧与底部的绿色外投影/残边。
- 保留：真实绿色幕墙、绿色机柜、罐体、铜管、青色窗户与标志，不能挖穿幕墙面板。
- 输出：`01_computing_center/manual_body.png`。

## 02_portal

- 输入：`source_raw.png`。
- `auto_body_reference.png` 只用于参考自动锚点和当前轮廓，不能直接作为成品。
- 删除：所有黄色幕布、平台左侧的黄色外投影、底边黄色残边。
- 保留：黄铜拱框、黄铜门槛、白色大理石平台和青色传送面，不能侵蚀金属拱框。
- 输出：`02_portal/manual_body.png`。

`depth_reference.png` 是轮廓与落脚位置参考，不是最终透明遮罩；以真实建筑边缘为准。
