# 豆包 Seedance 人物动作视频标准模板

适用：单张人物参考图生成可拆成游戏精灵帧的视频。将尖括号占位符替换后提交。

## 一次生成多个动作（总时长 6 秒）

```text
最高优先级：严格保持参考图中的同一个人物、脸部、发型、服装、装备、配色、材质、描边粗细、身体比例、画面风格和右向视角。不要重新设计，不要增删任何人物、装备、装饰或特效。不得水平翻转。人物从头到脚始终完整可见并位于画面中心，四周至少保留 10% 安全边距。

生成一个连续 6 秒、1:1 的人物动作视频，固定正交镜头，无透视变化。人物始终保持参考图的右向视角；禁止左转，禁止转成正面、背面或另一种斜侧角度。角色固定在原地，禁止向左或向右位移，禁止镜头移动、平移、缩放、旋转、抖动或跟随。

严格时间轴：
0.0-2.0 秒：<动作一，例如待机呼吸>。动作自然、幅度克制。
2.0 秒：自然回到与参考图完全相同的姿势和位置，不停顿、不定格。
2.0-4.0 秒：<动作二，例如原地向右步行循环>。身体中心固定，只允许四肢和随身装备按动作摆动。
4.0 秒：自然回到与参考图完全相同的姿势和位置，不停顿、不定格。
4.0-6.0 秒：<动作三，例如双手使用扳手工作>。只有在参考图没有扳手且本动作明确要求时，才允许临时出现一把扳手；除此之外不得新增或替换任何物件。
6.0 秒：自然回到与参考图完全相同的姿势和位置。

纯 #FFFFFF 白色背景，背景颜色逐像素均匀；无地面、无地平线、无接触阴影、无投影、无倒影、无环境光、无雾、无粒子、无速度线、无放射背景、无背景纹理。不得给人物新增动态光源、高光、阴影、渐变明暗或环境闭塞；参考图人物内部已经存在的固有材质明暗必须保持不变，禁止为了“平涂”重画人物。不要生成 spritesheet 网格、分镜框、边框、文字、水印、界面或多个角色副本。全程不得裁切、出框、拉伸、压扁或改变比例。
```

## 单动作循环版（精灵帧素材优先使用）

多动作合成只适合批量试样。正式制作单个循环动画时，用完整时长只生成一个动作，避免每段有效帧不足：

```text
最高优先级：严格保持参考图中的同一个人物、脸部、发型、服装、装备、配色、材质、描边粗细、身体比例、画面风格和右向视角。不要重新设计，不要增删任何内容，不得水平翻转。

生成一个连续 <4-15> 秒、1:1 的人物动作视频。人物在原地持续做 <动作>；身体中心与脚下位置固定，只允许动作必需的四肢和随身装备运动。动作节奏稳定，至少完成两个自然周期。开始和结束自然回到与参考图相同的姿势、位置和动作相位，首尾可循环；结尾不得突然减速、定格或倒放。

固定正交镜头，无透视变化。人物始终保持参考图的右向视角；禁止左转，禁止正面、背面或改变斜侧角度。禁止人物横向漂移，禁止镜头移动、平移、缩放、旋转、抖动或跟随。人物居中全身显示，四周至少保留 10% 安全边距，任何部位和装备都不得触碰或超出画面。

最高优先级一：纯 #FFFFFF 白色背景，背景逐像素均匀；人物脚下和四周不得出现任何灰像素、接触阴影、软影或投影。无地面、无地平线、无倒影、无环境光、无雾、无粒子、无速度线、无放射背景、无背景纹理。

最高优先级二：人物严格水平朝向指定方向。鼻尖、视线、胸腔、骨盆、膝盖和脚尖始终沿画面水平轴指向 <右侧/左侧>；禁止三分之四斜侧、正面、背面、回头、转身或水平翻转，整个视频不得发生视角偏转。

不得给人物新增动态光源、高光、阴影、渐变明暗或环境闭塞；参考图人物内部已经存在的固有材质明暗必须保持不变。不要生成 spritesheet 网格、分镜框、边框、文字、水印、界面或多个角色副本。禁止裁切、拉伸、压扁、改变比例或画风。
```

## 使用原则

- 一个正式循环动作对应一个视频；三动作 6 秒模板只用于低成本探索。
- 固定位置 Idle 必须显式锁定角色根节点：双脚、骨盆和躯干中心 X 坐标全程不变，禁止整体左右平移、左右滑动、左右摇摆和重心换脚；只允许垂直呼吸及头发/披风相对根节点的小幅运动。
- 提示词默认不写角色姓名、演员姓名或任何身份专名，统一称为“参考图中的原创游戏角色”，并明确“不涉及真人肖像”。角色名只用于本地文件名和资产记录，不进入豆包提示词。
- 若豆包反馈“出于肖像保护考虑”“暂不支持上传真实人脸素材”等拦截，禁止原文重复提交；先去掉提示词中的全部人物专名、身份指认和“同一个某某”等措辞，改成无专名的原创游戏角色描述后仅重试一次。若仍被拦截，停止图生视频并改用无专名文生视频方案或更换明显非真人风格的参考图。
- “无光影”约束环境与新增光效，不能同时抹掉参考图角色自身已有的材质明暗。
- 参考图不是严格侧面时，用“保持参考图右向视角”，不要强令模型改成纯侧面。
- 视频不是 spritesheet；网格、透明底、缩放和对齐由后处理完成。
