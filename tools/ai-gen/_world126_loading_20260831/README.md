# 世界-126·矿洞 Loading 背景

已按用户“生成10张不同构图，并在Loading界面随机放入”的指令接入开发目录。

## 使用范围

- 矿洞位面 `scene12` 使用 `world126Mine`；废弃矿洞地牢 `scene7` 的初/中/高级共用 `abandonedMineDungeon`，分别保留位面与地牢的加载标题。
- `data/loading-screen-config.json` 和 `public/data/loading-screen-config.json` 同步登记十图。
- 复用 `SceneManager.showLoadingScreen()`：每次进入上述位面或地牢的加载界面时等概率抽取一张，每张1/10，允许连续重复；一次加载期间不自动轮播。
- 复用现有浏览器图片预缓存、全屏居中cover、渐变遮罩和真实进度。不进入Phaser世界纹理生命周期。
- `minimumDurationMs: 1000` 与接入前通用fallback相同；现有热缓存缩短到350ms的处理保持不变，不保证每次完整显示1秒。
- 后续按用户要求将十图接入废弃矿洞三档地牢Loading；没有改主神空间、其他位面、地牢探索背景或任何玩法。

## 素材与来源

- 后端：Codex内置image_gen；10次独立生成，另对01/10进行2次角落杂记清理编辑。
- 提示词目标：16:9、2560×1440；**实际10张均为1672×941 PNG**，以真实输出尺寸入库。
- 正式目录：`assets/scenes/loading/world126-mine/`，合计22,334,647字节（约21.3MiB）。
- 原生生成输出唯一保留于正式目录，manifest的rawPath直接指向正式PNG；source只保留01/10清理前直接输入。十份完全相同的source副本已去重，不拉伸、不缩放、不进行40:9探索横幅裁剪。
- 01/10保留清理前直接输入（`source/original-*.png`）及清理提示词；清理采用ImageGen编辑，不声称其他像素逐一不变。
- 画风参考查看了 `assets/scenes/loading/world125-ruins-4.png`，生成调用未附参考图。
- 完整初始提示词见 `prompt-01.txt`～`prompt-10.txt`，修改提示词见 `prompt-01-cleanup.txt`、`prompt-10-cleanup.txt`；索引见 `generation-plan.json` 和 `manifest.json`。
