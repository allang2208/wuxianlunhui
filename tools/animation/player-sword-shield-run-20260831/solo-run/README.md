# 空副手单手剑：低持奔跑

2026-08-31按用户“单手持剑，另一只手不持盾时也采用持盾奔跑姿势，只让另一只手自由摆动”接入开发版。复用已确认的主手骨链、剑柄握点、剑角度/尺寸、掌部遮挡和原8帧腿步相；只改变空手副臂，不把盾牌姿态原样去盾后使用。

三轮修订：按用户确认的“有戒备的持剑跑”方向，副臂屈肘约90°、贴近身侧，手掌在腰侧到腹前小幅移动，后摆主要由肘部后移表现。上臂/前臂相邻帧最大角度变化收至12°/14°（含7→0回绕），替代二轮54°/67°的快速伸展；前臂角度依然是相对源图的绝对旋转，不二次叠加上臂角。

相位参考已有`../transitions/transition-config.json#runBodyPoints`的可见近侧髋—膝链，作为空手远侧臂的对侧腿参考：第2～4帧前送，第6～0帧后收。二轮第7→0帧前摆、第3→4帧后摆的分配已撤换；不再以“共用8帧”作为人体相位已经匹配的证明。这是基于源图及人工二维标点的动作设计，未测量三维骨骼或实机步态。

- 副臂仍取自同一角色的独立上臂和前臂切片，不拉伸骨段。沿用原身体和双肩的逐帧起伏，主臂、主掌、剑和身体比例不变；不另做胸腔形变。远侧上臂与前臂位于躯干之后，避免空手横盖胸腹。
- `rig.json`保存逐帧副臂角度与层序。`../export_solo_runtime.py`读取既有`rig-export.json`、`bodies/`和`parts/`，仅合成这个变体，不回写剑盾跑姿或V3。保持512源空间和原10FPS时钟，主手/剑数据从`data/player-sword-shield-motion.json#run`引用，不另建容易漂移的副本。
- `assets/player/sword-solo-run/run.png`及`run.json`：当前1张1448×1002紧裁图集、8帧，理论RGBA5.53MiB（二轮为1632×1002/6.24MiB）；摆幅收敛后透明紧裁范围缩小，不改变512源空间或身体显示尺寸。无新增掌部图集；`data/player-sword-solo-run.json`保存帧索引、双臂关节点和来源。
- `PlayerSwordShieldMotion`只对真实单手剑、当前副手槽空置且正在播放run时选择此变体，兼容已有RTS跑步显示，但不授予冲刺能力。当前武器模式为`weapon`时检查`offhand`，另一个模式检查`ring2`。其他副手物品、双手武器、法杖、枪弓不进入。
- 有盾时保持原剑盾分支。无盾时不进入V3预备、攻击或收势覆盖；停止跑步、切攻击/行走/待机、换武器后沿既有链恢复纹理与握柄原点。盾绑定为null，不创建虚假盾牌或防御状态；继承已有掌部深度、镜像、着色和石化停帧处理。

离线预览：`four-swords-both-directions.gif`为四把现有剑、左右镜像、完整8帧循环，100ms/帧；`cycle-contact.png`为骑士长剑逐帧接触表。这些是源像素合成素材，不是游戏截图或实机跟手证明。

涉及文件：`src/phaser/player-sword-shield-motion.js`、`src/phaser/scenes/BootScene.js`、`data/player-sword-solo-run.json`、`assets/player/sword-solo-run/`、导出器及本目录。未修改攻击、技能数值、原动画配置、剑盾素材或EXE。查看本次真实diff、必要调用点和离线素材；未运行测试或运行时验证，按约定由用户测试。

三轮只改`rig.json`的副臂角度/相位说明，复用原导出器更新图集、运行时关节点和两张离线预览；未改JS、导出器、原跑步播放区间、主剑/主掌数据或剑盾分支。仍跟随原生0～7帧、10FPS、800ms源循环，不单独降速、不增加额外摆臂循环。

四轮只把空手微调为自然握拳：`rig.json#offForearmPart`指定独立`fist/offForearm-fist.png`，导出器替换空手前臂切片并更新拳头中心参考，不覆盖原共用切片。新切片保留原前臂/手腕像素，仅接入image_gen制作的局部拳头；生成原图、提示词、裁切注册脚本与局部展示见`fist/README.md`。三轮角度、腕点、主手、腿部和8帧时钟不变，图集尺寸仍为1448×1002。当前循环预览和接触表均包含握拳修订。

需重新加载开发版载入新图集，重点确认：四剑双朝向、主手握柄、空手摆动、奔跑中装备/卸下盾、两套武器槽切换、run→walk/idle/attack及石化停帧。二维切片仍有遮挡/接缝的视觉限制，新增纹理的实际性能未测。

五轮微调：按“肩膀摆幅略大”的反馈，仅把空手上臂相对37.5°中位的摆幅缩小20%，全程跨度35°→28°；前臂每帧施加相同角度差，保持已确认的肘部弯曲。相邻帧上臂/前臂最大变化变为9.6°/11.6°。不移动肩部挂点、不重做胸腔，不改握拳、相位、主剑或腿部；当前图集与循环预览已重导，尺寸和时钟不变。
