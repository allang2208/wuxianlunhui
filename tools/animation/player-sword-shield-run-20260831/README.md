## 看候选与调整

- 双击同目录 `preview.html`：离线页面，素材嵌入 `preview-data.js`，不需要启动Vite或其他服务器。
- 可暂停在原0～7帧、慢放、左右翻转、切换现有四把剑、显示关节点、隐藏装备或双臂。选择“游戏基准144px”查看名义显示尺寸；该页面不模拟游戏摄像机缩放。
- 六个角度分别控制主手上臂、主手前臂、副手上臂、副手前臂、剑身、盾面。默认改当前帧，“整循环联动”将相同角度增量应用到8帧，超过滑条范围时会截断。
- “导出姿态JSON”下载修改结果，不写游戏。将下载文件的 `poses` 数组复制到 `rig.json` 同名字段，再执行素材合成脚本，可更新PNG/GIF和页面初始数据。页面刷新不会保留未导出的编辑。
- 肩点坐标、身体裁切范围和补片仍通过 `rig.json` 修改。第一版页面不提供肩点拖动、独立腕部转动或透视变形。

入口：`previews/knights-both-directions.gif` 是骑士长剑双朝向循环；`previews/four-swords-both-directions.gif` 同屏显示四剑双朝向；`previews/knights-cycle-contact.png` 展示完整8帧。均为离线合成，不是游戏截图。

## 可复用资产与职责

| 文件 | 用途 |
|---|---|
| `parts/mainUpper.png`、`parts/offUpper.png` | 主、副手上臂，分别绕自己的肩点旋转；没有用镜像副臂代替主臂 |
| `parts/mainForearm.png`、`parts/offForearm.png` | 主、副手前臂，含手掌，分别绕肘点旋转 |
| `parts/mainHand.png`、`parts/offHand.png` | 从对应前臂取出的掌部遮挡层；主掌盖住剑柄，副掌当前位于盾面后，不覆盖盾面 |
| `bodies/run-body-00.png`～`07.png`、`run-body-sheet.png` | 去除原双臂并作局部补片的身体底层；512×512单帧，4096×512精灵表 |
| `rig.json` | 人工输入：源文件、裁切多边形、关节、8帧姿态、装备尺寸依据 |
| `rig-export.json` | 可消费的派生数据：裁切框、局部枢轴、肩肘腕掌逐帧坐标、装备握点与层序 |
| `build.py` | 以现有素材生成本目录分层和预览；没有游戏运行时写入路径 |
| `preview.html`、`preview.js`、`preview-data.js` | 离线姿态编辑页面、渲染逻辑、嵌入素材 |
| `previews/parts-overview.png` | 六个独立部件概览，青色点为肩/肘旋转枢轴 |
| `previews/joint-authoring-contact.png` | 8帧骨链候选与原跑姿对照，供查看裁切和姿态 |

装备不烘焙到人物分层里；以后改角度、换剑、换盾不需要重新生成腿部。前臂已包含手掌，另有掌部遮挡层不代表实现了独立手腕骨骼。新攻击动作若需要不同手掌透视或肩背转向，仍可能需要补充素材。

## 来源、关节和尺寸

- 身体：项目现有 `assets/character/running.png`，仅使用正式实际播放的第一行0～7帧，10FPS，0.8秒循环。不启用后8帧、不重新居中各帧、不改变腿部步相。
- 双臂：项目现有 `assets/player/idle.png`，分别按主、副臂原像素裁切。
- 源坐标中的256行及以下直接复制原跑姿像素。上半身清除原臂后，第0～4帧腰腹/骨盆局部用同一跑姿第6帧无遮挡区域补齐；多边形与偏移完整保存在 `bodyPatches`。这是候选重建，不是恢复不可见的原始像素。
- 剑：`assets/weapons/1-rusty_sword_euip.png`、`knights_sword_ingame_v2.png`、`rune_sword_ingame_v2.png`、`night_flame_sword_ingame_v2.png`。合成脚本读取 `data/weapon-anim-config.json` 中各纹理独立握点，当前分别为Y=0.823、0.786、0.793、0.798，X均0.5。
- 剑显示尺寸依据当前126基础尺寸、0.75近战倍率、1.5剑倍率和0.63宽高比；以玩家144px显示尺寸换算到512px源图空间。第一版曾误读旧注释而使用0.625，衔接候选制作时已修正，脚本现在直接读取源码常量。具体结果随合成写入 `resolvedWeapons`，未修改正式尺寸。
- 盾：项目现有 `assets/weapons/woodshied-equip.png`，以当前原点 `(578/1024, 497/1024)`、可见高度比 `760/1024`、身体比例0.42合成。两款新优质盾候选不在本次注册或制作范围。
- 上臂角相对上臂源图，前臂角相对前臂源图，都是画面坐标角；前臂角不再叠加上臂角。上臂末端决定肘点，前臂变换决定腕和掌点，装备原点对准同一掌点。每帧重用相同骨长，没有通过伸长手臂追装备。
- 当前层序：远上臂 → 身体 → 近上臂 → 近前臂 → 剑 → 主掌遮挡 → 副前臂 → 盾。左右朝向对整套姿态共同镜像，不单独翻装备。
