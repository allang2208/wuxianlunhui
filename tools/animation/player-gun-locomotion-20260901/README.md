# 持枪走跑腿层重建

运行 `build.py` 会从项目内现有真源确定性生成：

- `assets/player/gun_walk_legs_v2.png`：严格 `4096×1548` 的 8×3 网格；前 21 帧保持原脚线、步幅和根点轨迹，只在腰胯拼接带加入同帧、同源的窄幅安全背衬。
- `assets/player/gun_run_legs_v2.png`：严格 `4096×512` 的 8 帧网格，保留旧腿部轨迹，统一增加 4px 左边界安全区，并从同一 `running.png` 帧补回腰部拼接带。
- `gun-run-splice-contact.png`：离线拼接检查图，不作为运行时资源。
- `gun-walk-twist-contact.png`：抽取 7 个关键帧，在 `-40° / 0° / +40°` 躯干扭转下生成的离线接触图；脚本同时检查全部 21 帧，强 alpha 接触为零会直接失败。
- `gun-grip-audit.json`：46 把运行时枪械的抓握解析覆盖、12 把手枪与 Super90/S12K 新校准点、方向依据及不重出枪图的判断记录。

方向、帧区间、裁剪与排除范围记录在 `manifest.json`。本脚本不生成或修改换弹动画，也不重算已认可的离散腿部轨迹。
