# 任务工作流

本页维护任务分流；系统字段和细节在对应分卷。测试、发布、外部设备及共享工作区权限只由 [AGENTS](../AGENTS.md) 管理。旧章节的固定步骤不得把局部改动扩大成完整生产或实机测试。

## 先选本次阶段

- **设计/评审**：给机制、规格、影响与建议，不生成或接入。
- **素材制作**：按已授权批次交付候选/正式资产与直接可看的预览；选稿状态和接入状态分开记录。
- **运行时接入**：按已有消费者登记资产、配置和生命周期；复用现有系统，新增字段必须找到消费端。
- **局部修补**：只修受影响资产/逻辑。Alpha去绿不重抽视频；数值改动不重做美术；已有动作不为流程形式再插帧。保留帧序、比例、时钟、碰撞与获准身份，除非本次明确要求改变。

同一任务已授权多个连续阶段时直接推进，不把内部步骤变成重复确认。当前只授权候选时不替换正式资产。

## 公共资产步骤

1. 定用途、游戏显示尺寸、参考和交付阶段；角色预算读 [16](16-character-sprite-production.md) §16.1。
2. 在材质/视频前确认几何或动作关键帧；身份、相机、结构不合格先修源。
3. 采用相关模板补充资产特有信息，公共提示词只注入一次。模型、采样步数与批次默认值只查 [生成操作](../tools/ai-gen/WORKFLOW.md)；用户指定优先，不在分卷复制参数。
4. 直接视觉判断姿态/结构，像素或Alpha数据回答尺寸/边缘问题；两者各有适用范围。连通域数量不能证明主体数量或动作正确，外部识图不作为通用必经步骤。
5. 交付保留最小可重建链：获准来源、直接编辑祖先、提示词/参数、必要脚本/模型、正式产物与最终预览。manifest记录来源、接受状态、输出和必要依赖；局部改动只更新受影响项。
6. 清理仅限本任务明确可再生的中间物与获准废案，不按“运行时未引用”删除来源，不触及共享队列或其他任务。无需为简单任务新建一套清理/哈希系统。

## 动画

用途/动作清单 → 身份参考与同类动作基准 → 朝向/关键姿态 → 视频 → 有效动作窗口与固定比例 → 按需插帧 → 正式表/时钟 → 最终GIF。

- 朝向门槛、根点、接触帧和时钟的唯一公共定义在 [16b](16b-animation-alignment-and-timing.md)。视频提交与恢复只查 WORKFLOW §3.6。
- 插帧是质量工具，不是每张表的必做项。需要平滑且源关键帧正确才做一次2×RIFE；已有流畅动作保留源帧，记录未插帧即可。采用RIFE时必须遵守16b §4的关键帧、循环、Alpha与事件映射要求。
- 动作时长服从机制和已接受节奏；约1.5秒仅是偏慢普通攻击的参考，不是全局改速规则。
- GIF使用最终播放时钟，说明是否为素材预览；源素材完成不代表已接入。局部修补只交付受影响动作及必要对照。

### 动作清单与接续记录

新制先按实际玩法列出所需动作，不默认生产四动作套装：近战关注接触动作，远程关注释放/装填，工人关注作业/搬运，NPC仅制作实际展示的状态。待机、移动、死亡、受击等是否需要独立表，以现有状态机消费者和设计为准；不制作独立表时注明合法复用或现有表现，不能漏掉消费者必需的状态。用户已指定动作清单时按其范围执行。

复用现有任务manifest记录以下信息，不创建第二份进度真源，也不要求批量迁移旧清单：

| 信息 | 记录方式 |
|---|---|
| 动作范围 | 动作名、对应玩法状态、循环/单次、新制或复用来源；未确定项标待定 |
| 当前阶段 | 母图待选、关键帧确认、视频制作、后处理、素材完成、已接入；多动作进度不同时按动作记录 |
| 已接受结果 | 来源路径与接受依据；助手离线核对和用户选稿分别记录 |
| 下一步 | 明确到动作与操作，附尚未解决的问题及当前授权终点 |

记录是文档约定，不是新增运行时字段；优先使用清单已有同义字段。重建脚本会覆盖manifest时同步维护其元数据来源。接续先读记录和对应现有产物，从未完成步骤继续；已接入不等于实机通过，授权范围不能由阶段标签推导。

### 基准如何定位

- 两足普通人形的体量入口：`data/enemy-config.json` 的 `minerZombie`；步兵/施法友军体量入口：`data/hamster-priest-config.json`。读取当前配置指向的实际动作，不复制旧文档帧号与数值。
- 体量参考不自动成为方向参考；四足、骑兵、器械、飞行单位按同类已认可动作选择，按16b §1.1登记实际资产路径与帧索引。尚无同类基准时先明确本次关键姿态，不臆造已认可样本。

### 返工从哪里继续

| 问题 | 回到哪一步 |
|---|---|
| 身体朝向、相机或关键姿态错误 | 关键帧；未通过不提交视频 |
| 视频身份漂移或结构形变 | 视频来源/生成；不靠抠图与插帧掩盖 |
| 绿边、Alpha残留 | 受影响帧的抠图/边缘处理 |
| 插帧重影、武器弯折 | 回到正确源帧，按16b §4选择保留源帧或修复插帧 |
| 接触/出膛时机不符 | 动作时钟和实际消费端；源动作正确时不重抽 |
| 脚点漂移 | 先定位裁框、锚点换算或源位移，只修出错环节 |

返工后只更新受影响产物及其必要派生记录；不重新生成已接受的其他动作，不扩大测试授权。

## 敌人与NPC

定位/攻击类型 → 复用基类与消费者 → 配置/动作时间轴 → 必要素材 → 生成/掉落/图鉴入口。

- 需要新增/重做动作时直接进入 [动画工作流](#动画)，完成本次授权的素材阶段后返回此处接入；仅改数值/逻辑不触发动画制作。
- 普通近战、连击、范围位移、远程分别走 [09](09-monsters-npc.md) 的攻击合同；一项攻击一个伤害源，不能用扩大伤害区修补错位动作。
- 普通怪优先配置复用；特殊Boss先定义状态、打断/死亡取消、变身/召唤依赖，再生产动作，不为普通怪新建多技能架构。
- `render`/碰撞、纹理键、有效帧和实际配置消费者见 [01](01-core-rules.md) 与09。NPC使用自己的配置读取位置，不能照搬敌人字段。
- 纯NPC不套用攻击/掉落步骤；仅新增标签、数值或改素材时，只走相关分支。

## 友军

| 类别 | 必要接入 |
|---|---|
| 军事单位 | 定位与招募/科技/人口 → 战斗与指令 → 素材/驻留 → 升级传播、前后台生产与存档恢复 |
| 工人/平民 | 岗位与生产 → 移动/交付 → 前后台恢复 → 必要动作，不强加攻击四件套 |
| 侍从 | 跟随/索敌/技能 → 队伍/恢复 → 素材；使用 [10b](10b-companion-ai.md) 的AI入口 |

- 需要新增/重做动作时直接进入 [动画工作流](#动画)，按兵种玩法选动作；素材阶段完成后返回本类别接线。仅改招募/数值/AI不触发动画制作。
- 军事单位必需登记 `friendly-unit-assets.js`，对齐配置id、animId与unitKind；按需驻留，不向BootScene补全量常驻副本。完整接线查09“友军资源驻留登记”。
- 招募人口、科技限制、后台估算和升级传播按 [07](07-world122-defense.md) 对应合同；死亡、取消与切场不得遗留攻击事件、占用或重复奖励。

## 建筑与环境道具

用途/逻辑占格/通道 → 同相机白模合成 → 材质候选 → 选稿精修 → Alpha及语义层 → 接地/遮挡/阴影与玩法接入。

- 完整母场景中原位渲染组件再裁切；楼梯/平台有真实承托。几何与相机先合成确认，再投入材质精修。
- 逻辑footprint、visualFootprint、碰撞、遮挡和阴影分别维护，不能通过改占格修视觉；地面与立体遮挡层按语义拆分，动态投影由游戏负责。
- 简单环境小物可按现有Blender直渲路线交付；固定结构AI精修参数查 WORKFLOW §1.5。无需为每个小物强行跑完整候选/精修两阶段。
- 单建筑层数、材料与特殊设备约束存资产manifest；公共结构细节查 [02](02-ai-asset-pipeline.md) 与 [组件参考](references/world122-building-components.md)，运行逻辑查07。
- 选稿局部修补保留直接祖先，不重新生成整个建筑。无玩法的场景装饰不套生产/科技/后台经济流程。

## 装备

身份与数值 → 必要贴图/图标 → 数据登记 → 效果消费者 → 本次要求的获取入口和展示。

| 品类/变更 | 按需附加步骤 |
|---|---|
| 枪械 | 弹药/开火模式/枪口/音效；改姿态才进入掌点和动画挂点 |
| 近战 | 攻击时间轴与伤害链；新动作才走玩家动画流程 |
| 盾牌 | 新盾保留防御斜视、正面、背面和图标；纯数值修改不重做这些素材 |
| 护甲/首饰 | 实际属性消费与展示；仅设计包含套装时登记套装 |
| 祭品 | 统一效果键、持续时间与生命周期；不复制普通装备增益链 |
| 新效果键 | registry、聚合/消费者、配置闭环；已有键不新增平行实现 |
| 图标变化 | 正式高分来源与运行时镜像分离；按当前工具生成受影响镜像 |

细节查 [04](04-weapons-equipment.md)、[盾牌工作流](../docs/shield-development-workflow.md)；运行时镜像尺寸服从当前消费者，不把历史1024/1536源图规格当成UI加载要求。新增装备不默认新增商店、套装、改造或独特机制。旧验证清单只供用户授权测试后按变更选择。
