# 动画朝向、结构与时钟合同

> 本文件为 game-dev 技能库分卷，主索引与目录见 `../SKILL.md`。

适用于新增、重抽或接入怪物、友军、工人、侍从等单位动画。这里只记录可复用合同；具体任务进度、选稿与生成批次进入 `CHANGELOG.md`、任务 manifest 或制作报告。

## 1.1 动画开工必做：相机、朝向与动作轴确认

1. 先读同类已认可单位的实际配置和动作图集，至少查看三个不同动作阶段。manifest登记参考素材、配置、0-based帧索引、相机俯视感、身体朝向、动作轴和根点策略。
2. 身份参考与运动参考分开。武器、口器或局部突起朝右，不能替代胸胯、足尖、运动轴与根点核对；母图获准也不自动批准移动方向。
3. 尚未生成的视频先过同角色动作关键帧；已有视频先看24～32点联系图和动态预览。方向或相机不合格时直接重抽，不用抠图、RIFE、旋转、拉伸或裁切伪装修复。
4. 用户已指定方向、参考或同意继续时，助手按既有授权完成离线核对并推进，不重复增加确认门槛。离线素材检查不等于实机验收。

没有头、胸、胯、足尖或左右行进轴的抽象怪物不能硬套人形朝向检查。此类单位在manifest显式登记`orientationInvariant/allDirection`，改为锁定相机俯视感、壳体/孔洞主轴、中心根点、拓扑标志和运动轴；运行时固定`flipX:false`。装饰裂缝、孔洞或一片突起不能被臆定为脸朝向，每个动作仍需与同一相机、比例、中心根点和身份标志并看，防止生成结果变成转身、横环、缩放或镜头推近。

## 2. 结构安全派生

H3等源片出现结构形变，而已有动作帧已经通过身份门槛时，只允许两类派生：对完整画布做逐帧整数平移，或精确复用、反放已接受源片中的完整帧。禁止缩放、旋转、局部变形、插值、重绘或把派生片登记成新的生成结果。

派生记录必须写明源视频、逐帧操作、接点误差和用途。该方法适合全向悬浮循环或一次开合后的恢复，不适合死亡、转向、身份变化或需要新动力链的动作。

## 3. 运行时接入

- 各动作可用独立`frameLayouts`，但必须还原到同一世界比例和中心根点；不能逐动作按Alpha边界放大。
- Collider负责世界移动，素材内漂浮和呼吸由单一动画时钟推进；避免Collider位移与表内根点位移重复。
- 攻击、命中、牵引、脉冲、声音和恢复使用同一手动时钟与0-based跨阈值事件。每个目标在结算时复查存活、同层、实际地面形状与LOS。
- 自管攻击不得再进入通用普攻结算；视觉预警可以与已标定前摇重叠，但不能额外叠加一轮等待。

## 4. 定稿清理与来源保留

定稿后可删除明确标记为拒绝、重复或可重建的任务本地大文件，但必须保留获准母图、参考、提示词、provider响应、生成参数、最终源视频、成品精灵表、预览与运行配置。若删除被拒视频二进制，至少保留其提示词、provider JSON、基础统计、拒绝原因和清理manifest，并同步修正报告中的链接。

禁止用笼统目录清理或`git clean`处理并行工作区。清理清单要列出精确路径、文件数、释放字节数和仍保留的正式来源；只有`stillPresent: 0`等静态证据时才可声明废案清理完成。
