# 第16卷：角色精灵图生产规格

任务阶段、动作清单与接续见 [动画工作流](00-workflows.md#动画)；方向、根点、插帧与时钟见 [16b](16b-animation-alignment-and-timing.md)。本卷维护生产入口和专属器械条目，不复制后端参数。

### 16.1 用途与预算

制作前按量产单位、少量特殊单位或首领选择用途档位；预算数值读取 `tools/ai-gen/character-sprite-standard.json`，不把旧案例磁盘大小当成运行时成本。按实际纹理键、PNG解码尺寸及必要伴生资源统计；同一图片重复注册不能当作共享。该估算不是设备实测性能，检查仍按本次授权执行。

### 16.2 来源与交付

同角色固定主体像素比例，各动作使用固定裁框并同步脚点；不能逐帧按包围盒缩放或居中改写获准动作。有效帧和endFrame按实际布局登记。高分来源与运行时副本分离，保留最小可重建链。插帧是否必要由16b §4决定，最终GIF使用实际播放时钟；素材完成、接入和用户实机验收分别记录。

#### 双人器械与多视频攻击衔接

- 双人和器械作为一个资源族与实体，尺寸按单名工程师主体高度对齐已确认步兵；炮管、轮轴和投石臂不能进入人物身高基准。视角参考既有单位的略俯视右向镜头，不把“朝右”误解为完全侧视或炮管必须屏幕水平。
- 已接受的开火动作追加取弹段时，保留原生关键帧输入，以 `sourceSegments` 分别登记原攻击和取弹视频、源帧、总时长与接缝；统一脚点和制作比例后按16b §4决定是否做一次RIFE，不对成品插帧二次插值。原出膛/退壳/装填时点不随尾段追加而移动。
- 渲染、声音事件、AI动作锁、前台面板DPS和后台估算共用最终墙钟；攻击周期至少覆盖完整动作。死亡保持单次播放、末帧停留和原朝向，不继承开火事件。清理后保留原攻击关键帧快照、最终GIF和复合动作入口，旧单视频入口不得覆盖已接入的复合动作。
- 来源示例：`tools/ai-gen/_engineering_line_completion_20260830/resupply_sprites.py` 与 `RESUPPLY-DELIVERY.md`。素材/代码接入与用户实机验收分开记录，不把离线容量计算当成实际显存测试。
