# 第16卷：工程器械精灵图生产条目

本任务分支仅提交本次工程器械条目；共享目录的其余统一生产标准仍由所属任务发布，合并时保留其完整分卷与本条目。

#### 双人器械与多视频攻击衔接

- 双人和器械作为一个资源族与实体，尺寸按单名工程师主体高度对齐已确认步兵；炮管、轮轴和投石臂不能进入人物身高基准。视角参考既有单位的略俯视右向镜头，不把“朝右”误解为完全侧视或炮管必须屏幕水平。
- 已接受的开火动作追加取弹段时，保留原生关键帧输入，以 `sourceSegments` 分别登记原攻击和取弹视频、源帧、总时长与接缝；统一脚点和制作比例后再做一次RIFE，不对成品插帧二次插值。原出膛/退壳/装填时点不随尾段追加而移动。
- 渲染、声音事件、AI动作锁、前台面板DPS和后台估算共用最终墙钟；攻击周期至少覆盖完整动作。死亡保持单次播放、末帧停留和原朝向，不继承开火事件。清理后保留原攻击关键帧快照、最终GIF和复合动作入口，旧单视频入口不得覆盖已接入的复合动作。
- 来源示例：`tools/ai-gen/_engineering_line_completion_20260830/resupply_sprites.py` 与 `RESUPPLY-DELIVERY.md`。素材/代码接入与用户实机验收分开记录，不把离线容量计算当成实际显存测试。
