# 仓鼠防暴队移动循环修复（2026-08-30）

本轮只处理用户反馈的防暴队移动动画卡顿和循环问题。沿 `SKILL.md` 索引查阅第02/16分卷及 `game-dev-lessons` 动画条目，对照正式素材、源视频和局部播放链。

## 根因与处理

- 播放配置已有 `repeat: -1`，`GameScene` 连续移动时不会每帧重启动画，因此不是漏设循环开关。
- 原版取视频第0～120帧、每4帧取一张，共31张源帧，以6fps送入插帧，最终62帧/12fps，包含整段5.17秒动作。原片中间存在完整且稳定的24原帧步态，不需要重新生成视频。
- 更直接的顿挫来自插帧时间点。RIFE目录模式使用 `i * 输入帧数 / 输出帧数` 采样；旧脚本请求 `2N-1` 张，却把偶数文件名全部当成半步，导致中间帧逐渐偏向下一源帧。31张源帧时，最后一组内部插帧的位置约为0.984，而非0.5，造成“一跳一停”。公式见[与本地发行版对应的RIFE源码](https://github.com/nihui/rife-ncnn-vulkan/blob/20221029/src/main.cpp#L676-L710)。
- 修正共享离线工具：目录请求改为 `2N`，中间帧固定落在0.5；忽略目录模式重复末帧。最终单次动作仍为 `2N-1` 张，循环仍为 `2N` 张，最后到第一张的中间帧单独生成。不改变原有源帧像素、透明处理或其他修复选项。
- 移动重新选取原片 `[72, 96)`，每2帧取样，12张源帧/12fps，RIFE后24张/24fps，正好1秒；第96帧只作为同相位端点参考，不重复收入图集。
