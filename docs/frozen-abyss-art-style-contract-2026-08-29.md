- 几何与渲染：`tools/ai-gen/building-component-kit.py`、`tools/ai-gen/settlement-building-pack-blender.py`。
- 相机与尺寸：`tools/ai-gen/_settlement_building_pack_20260821/manifest.json`。

## 必须继承的项目画风

1. 偏写实的策略游戏PBR，而非卡通、手绘描边或照片级脏污。
2. 大块连续材质面优先；磨损、裂纹与颗粒只保留稀疏的中尺度信息。
3. 低饱和、中性对比、克制高光；材质细节服从轮廓和玩法可读性。
4. 固定30度正交相机、模型根旋转44.8度；单帧不得重新旋转、镜像、拉伸或换光向。
5. 柔和中性左上顶侧光、宽缓高光、仅构件接触处允许克制AO；禁止模型外投影阴影、轮廓光、霓虹与泛光。
6. Blender白模和Depth是结构真源；提示词不得改变层级、厚度、轮廓、拓扑或占格。

## 深渊的材质翻译

- 顶层：压实、轻微风蚀的雪檐，使用连续大面，不做泡沫雪或规则方齿。
- 中层：低饱和蓝灰色分层冰断面，以宽层理和少量结构裂缝表达厚度，不做透明霓虹水晶墙。
- 底层：大面积安静的近黑藏蓝深渊；内部格边不倒角、不提亮，避免出现棋盘线。
- 点缀：每条暴露边最多一处低矮自然碎块；禁止等距排列冰锥、城垛、砖缝、栏杆或建筑装饰。
- 接缝：相同方向边使用同一端点截面；变化只发生在边段中部。相邻格不得出现双封边、端盖、台阶、亮线或光向断裂。

## 16拓扑合同

- 位顺序固定为`+u / +v / -u / -v`，分别对应bit 0～3。
- 邻接位为1：该边完全开放，不出现雪檐或冰壁。
- 邻接位为0：该边包含完整雪檐与冰断面。
- 15号是四面连接的内部深渊格，只保留深渊底层；0号是四面暴露的孤立格。
- 所有格使用`128×64`逻辑占格。深渊底层允许极小过绘消缝，雪檐和断面不得越过标准接缝截面。
- 正式美术不让模型分别发明16张独立图：只生成一张深渊底层与四个固定光向边段母件，再由确定性脚本按掩码组合16帧，以消除跨掩码的颜色、光向和裂纹漂移。

## 正式资产阶段门禁

1. 白模审批：16拓扑总览、Depth、可编辑`.blend`齐全并实际查看。
2. 拼接证明：至少包含长直边、凸角、凹角、内部格与不规则连通块；必须使用真实选帧合同组装。
3. 结构候选：只通过正式候选生成器和manifest，公共`world122-building-v5`仅注入一次，资产提示只增加冰原身份。
4. 精修：只提升雪、冰和断面的材质质量，不得改变拓扑、断崖高度、相机或格边截面。
5. Alpha与接地：正式帧真透明、无模型外阴影、无脏RGB、无内部网格线；不得用非等比缩放修正接缝。
6. 运行时接入：用户确认候选后才进入正式资源目录；逻辑碰撞、寻路和房间生成继续由现有程序化格网控制。
