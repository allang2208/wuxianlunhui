# 四时代九条兵线数值调整 v4

初稿：2026-08-31；v4：2026-09-01。
本轮承接四时代整体调参授权，并按用户对低阶兵打不过普通怪的反馈继续回调。

**v4记录16种I/II现有兵种的回调目标；投石组、野战炮组沿用v3；III中的战壕突击兵与仓鼠近代炮兵组已接入，其他项目仍按各自发布状态为准，IV九种不改。** v4取代v3作为后续接入依据。v3过度追求每人口指标逐代上升，压低了初期单位的基础战斗能力；本版先恢复普通怪对抗底线，再安排时代提升。表格数值尚未全部经过实战验收。

## 1. 范围与取舍

- 九条主兵线：反装甲、侦察、突击、盾卫、常规射手、重火力、轻骑、重骑、炮兵。教会和位面特色单位不在本轮范围。
- 固定IV的属性、能力、费用、人口、动作与武器，也不削弱怪物。本轮只改16种I/II的生命、部分六维、伤害、战士横扫副目标倍率及招募经济。
- 保留I/II人口、普通攻击周期、移动速度、攻击帧、碰撞、近战起手/接触距离和已确认动画。v3的毒箭限3层、弩手穿甲/贯穿限制、侦察视野、骑兵冲锋参数继续保留。
- **不再要求每人口输出和耐久严格逐代上升。** 低人口旧兵允许保留性价比与编队优势；九线的出生单兵生命和无甲基础普攻DPS均逐代提高，升级还获得射程、控制或攻击方式的变化。不能据此宣称所有目标、研究等级和人口编组都严格同序。
- 普通僵尸作为低阶基本对抗参照；黑狼、棕熊等较强普通怪需要兵种配合。rank为normal不代表统一战力，不要求每名初级兵单挑所有普通怪。
- 八张已确认母图保持：波波沙与周期反坦克手榴弹、莫辛纳甘、A10、钢盾与TT、SVT-40、单人BAR、木托骑枪、传统长矛。**III重骑无爆炸、无助推；BAR无电台、无背包供弹技能，携行弹链不作为BAR供弹方式。**
- III仅战壕突击兵完成`unitTypes`、实体、AI、动作和独立科技闭环；钢盾仍占位，因此III整级不启用。其他III单位不新增运行时实体，炮兵母图尚未制作，其编制和参数仍暂定。

## 2. 对普通怪的基础预算

参照当前普通僵尸配置：生命120、力量10、敏捷15、体质15，派生攻击13、护甲25，攻击间隔2秒，无额外技能。比较对象是**新招募Lv.1士兵对该僵尸的基础配置**，不是声称双方同等级。

## 4. 能力梯度

### 4.1 反装甲：长枪 → 长戟 → 波波沙投弹 → 现代反载

- I/II保留已有巨人杀手研究与近战定位，本版普攻24/1.8秒、34/2秒；不新增手榴弹或火箭。
- III：175生命、波波沙15/0.7秒、540射程；周期投掷反坦克手榴弹，150物理、反载×1.6=240，冷却12秒、首发等待4秒、投掷射程320、半径80、边缘50%，投掷与恢复占用1.3秒停枪。
- IV不改：180生命、16/0.65秒、650射程；火箭200、反载×2=400，冷却10秒、首发3秒、半径110、边缘55%、恢复1.1秒。弹道最大飞行预算890不等于锁定射程，锁定仍为650。
- III巨人杀手只取同级**加成部分×0.8**：骑兵最高+56%、大型最高+24%；不是整体伤害×0.8。无研究不生效。
- 冷却从实际释放计；释放后空投也计冷却，释放前取消不消耗。没有近距投掷目标则正常开枪，不为投弹主动放弃射程贴脸、不攒多枚投掷。母图道具数量不是弹药上限。
- 载具判定沿上位的_isVehicle与vehicle/载具/机械分类，不泛化到全部大型、骑兵、首领或建筑；爆心只结算一次，仍检查地形/高度/墙体。

### 4.2 侦察：斥候 → 游侠 → 莫辛 → 现代狙击

- I/II生命100/120、普攻32/2.2秒和50/1.9秒，迷雾视野1400/1600；III拟1750；IV保持1900。昼夜、天气和现有scout视野规则不改。
- I保留解锁后的标记支援，II不施加标记，专注稳定单体输出；已纠正游侠说明，避免把未接入能力写成已有能力。
- III：135生命、168/4.2秒、950射程；标记概率为IV同研究等级×0.85（Lv.1为25.5%、Lv.10为63.75%），持续2.7秒，承伤增幅12%。IV为30%～75%、3秒、15%。
- III保留现代狙击对大型/领主伤害×0.75，基础168结算前预算126。单兵该类目标基础DPS为30，IV约34.69；不绕开上位限制。
- III弱标记不能覆盖、叠加或续满其它来源的更强标记；强效果保持自身剩余时间，同强度按原刷新规则。来源削弱与共存保护仍待III实现。

### 4.3 突击：双手剑 → 冠军 → A10 → 现代特战

- I生命225、普攻32/1.8秒，固有副目标倍率由v3的20%回调为30%（仍低于调参前45%），保留120°近战横扫与命中几何；横扫研究只增强副目标包。
- II生命300、52/2.1秒，沿用现有单体重剑攻击，**冠军没有新增AOE**。
- III：80/2.4秒、250射程、完整扇角24°，最多3目标，副目标40%（基础32）。IV为88/2.4秒、300射程、30°、副目标55%，当前未配置目标数上限。
- 三目标无甲、无研究、按包取整：III为(80+32+32)/2.4=60DPS；IV约(88+48+48)/2.4=76.67。主目标不重复吃副目标伤害，不拆成多颗各80的霰弹。
- III不加自动防御、减速、眩晕或爆炸，每个目标独立检查扇区和LOS。

### 4.4 盾卫：小盾 → 方阵 → 钢盾与TT → 防暴霰弹盾

- I/II生命恢复到300/420，普攻24/1.8秒和30/2.2秒；保留现有自动防御研究，仅改生命、六维与攻击参数，不重复结算盾挡。
- III：540生命、34/2.4秒、240射程、TT单体；无霰弹多目标、无减速。IV仍为45°扇区最多5目标各36，并附15%减速1.5秒。
- III自动防御概率＝IV同级概率×0.9，成功减伤45%；Lv.1/6为27%/49.5%。IV实际为30%/55%、成功减伤50%。III无研究时不触发，不叠加父类的另一层完整格挡。
- 原共享描述“上限50%”与现有Lv.6实际55%的差异保持原状，本轮不改变IV定义。方阵仍有每人口肉盾价值，III不以牺牲低阶可用性换取全指标领先。

### 4.5 常规射手：短弓 → 长弓 → SVT → 突击步枪

- I/II生命120/150，普攻32/1.8秒和72/3.2秒，长弓900射程保留；III为70/1.8秒、680射程、145移速，IV保持72/1.6秒、720射程、155移速。
- **沿用v3毒箭3层上限**：研究概率与等级不改，配置maxStacks=3。同一目标当前中毒达到3层后，毒箭不再加层或续时；不清除、不压低其它来源已有的更高层数，不修改公共中毒伤害/衰减规则。单位详情显示上限。
- 当前普通中毒每层每秒1伤害；只由该毒箭产生时，最多附加3DPS。无甲单目标I普攻加满层毒约20.78，低于II普攻22.5；绕甲、免疫和持续时间有不同价值，不宣称所有护甲场景严格同序。
- III/IV保持单体枪械，不加中毒、标记、供弹、额外穿甲研究或独立弹匣资源。长弓在超远程和人口紧张时仍可有用途。

### 4.6 重火力：重弩 → 火枪 → 单人BAR → 现代重机枪

- I为50/3.4秒，固定穿甲10%、最多2目标、次目标35%；保留v3对原25%穿甲和75%次目标倍率的限制。
- II为40/2.2秒；现有穿甲研究25%起、最高40%不改，无研究则无穿甲。保留火枪的单体重甲专长，不新增跨兵种研究倍率协议。
- III：28×3/3秒、700射程、100移速、固定20%穿甲、最多2目标、次目标50%。IV不改：30×3/2.8秒、760射程、105移速、固定25%穿甲、次目标60%。两代机枪都不另叠火枪研究。
- III三发暂按相对首发0/300/600ms；IV现有0/250/500ms不改。待实际三次开火动作定释放事件，不借用上位帧号；移动取消尚未释放的子弹，已发弹道继续，逐弹去重并遇墙停止。
