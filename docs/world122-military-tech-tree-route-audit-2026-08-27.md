# World-122 军事科技树路线与研发节奏审阅（2026-08-27）

## 结论

军事科技树改为“纵向建筑时代骨架 + 横向建筑专属支线”：仓鼠草屋初始可建，“仓鼠草屋·I级”位于左上角并在新游戏、旧存档中默认完成。玩家由此向下依次研究军营建制、阵地射击、骑兵学和战地神学，逐级开放军营、靶场、骑兵学院与教堂；草屋横向则进入侦察编制与仓鼠草屋军备。每座建筑的基础兵种、二级编制和三级编制在本行向右展开。

黑火药从原先过早、折算仅260点的普通火药节点，调整为靶场二级阶段的1950点时代门槛。它独立解锁仓鼠火枪，并作为草屋、军营、靶场、骑兵学院、教堂全部三级编制的共同前置。v36曾因长弓未完成而让黑火药临时直达靶场三级；v40在仓鼠长弓完整落盘后取消该临时绕行，恢复“黑火药→长弓整编→靶场三级”的正常换代顺序，三级节点显式使用长弓整编与黑火药双前置 AND 门槛。

## 主要问题与处理

1. 旧军事树只有“军事组织”一个根，但军营、靶场、骑兵学院、教堂均从根节点并行开放，玩家无需经历军事建筑时代推进。
   - 调整为同列纵向骨架：草屋军备 → 军营 → 靶场 → 骑兵学院 → 教堂。
2. 旧“火药学”折算成本仅260点，却提前位于靶场一级基线之前，无法承担武器时代转换。
   - 更名为“黑火药”，折算成本调整为1950点，放在靶场二级阶段。
3. 仓鼠火枪虽然拥有独立科技所有权，但旧整级换代过滤会在仓鼠长弓仍占位时把火枪排除出招募选项。
   - 为产兵配置增加通用 `supplementalUnitUnlocks`：独立单位科技完成后，可在所属整级尚未完整启用时作为补充招募选项；正式进入该级或更高等级后仍服从槽位换代。
4. `producer-buildings.json` 中十个二/三级募兵层仍记录旧的1500/9900折算预算，与v33实际1560/4140不一致。
   - 全部同步为1560/4140，避免科技详情与长期规划继续引用过期预算。

## 新军事路线

| 行 | 纵向骨架/入口 | 横向支线 | 三级共同门槛 |
| --- | --- | --- | --- |
| 草屋→特战 | 仓鼠草屋·I级（初始完成） | 侦察编制 → 仓鼠草屋军备 → 斥候营地 → 特战基地 | 斥候营地 + 黑火药 |
| 军营 | 军营建制 | 盾阵学 → I级基线 → II级 → 现代步兵军营（仓鼠特战/仓鼠防暴队） | 军营II级 + 黑火药 |
| 靶场 | 阵地射击 | I级基线 → 黑火药 → 长弓整编 → III级 | 长弓整编 + 黑火药 |
| 骑兵学院 | 骑兵学 | 重骑兵 → I级基线 → II级 → III级 | 骑兵学院II级 + 黑火药 |
| 教堂 | 战地神学 | 仓鼠牧师 → 主教议会（仓鼠主教）→ 圣迹大教堂（仓鼠大主教） | 主教议会 + 黑火药 |
| 指挥 | 从侦察编制后的草屋军备分出 | 战术指挥 → 常备军令 → 集结网络 → 远征后勤 | 不受黑火药限制 |
| 军事支援 | 从军营/盾阵横向分出 | 军械保障/军需标准化；战地医疗/医疗标准化 | 不受黑火药限制 |

## 存档与边界

- 科技树当前版本为v40；仓鼠草屋I级改为初始完成的纵向骨架起点，旧档固定补齐该节点，已完成草屋军备的旧档同时补齐新增前置侦察编制；曾完成靶场三级但未完成二级的临时绕行存档会补齐长弓整编，保持高阶权限且避免完成节点倒挂。
- v34及更早存档的黑火药未完成进度按旧260点成本的完成百分比迁移到1950点。
- 旧档已经完成的军事科技不会回锁；恢复时会递归补齐本次新增的非占位军事前置，包括三级科技所需的黑火药。
- 兵营III级已由仓鼠特战替换旧动力甲规划，并与仓鼠防暴队共同完成整级开放；靶场II级已由仓鼠长弓与仓鼠火枪共同完成并正式纳入三级前置。其余规划占位仍不可研究：骑兵学院III级等待侦察车/坦克，教堂II/III级等待仓鼠主教/仓鼠大主教。
- 黑火药完成后可先通过补充招募使用仓鼠火枪，但不会让长弓或三级兵种越过对应科技门槛，也不会泄漏侦察车、坦克或法术占位兵种。
