# 大地图控制、寻路与入营优化方案及实施

2026-08-31。按用户“帮我做优化方案，并优化实施”落地到本地开发源码。已查看本轮真实差异与必要局部调用链，未运行测试或运行时验证，按约定由用户测试。没有构建、提交、推送或同步固定EXE。

## 目标与边界

解决三个现有问题：地图只支持左键选格后按按钮；行军改令会放弃当前路段；返营只支持出发基地且抵达后需要再点击一次。保持一支玩家亲征军团、24名士兵、共享世界时间和原生产人口契约。

| 目标位置 | 右键 / 对应按钮的行为 |
|---|---|
| 普通地格、我方战略据点 | 行军至该格，不自动创建或进入场景 |
| 敌军兵旗或敌军占格 | 追击指定军团，每到一格按敌军当前位置重新寻路 |
| 敌方城镇、据点 | 行军攻占；“摧毁”仍须明确选择原有摧毁按钮 |
| 正在围城的基地 | 下达追击围城军或解围命令，不能直接入营跳过战斗 |
| 已接通、未被毁且没有战事的己方建设基地 | 行军到信标格后自动入营；已在该格则等待下一次战略调度进入 |

左键选择、左键拖动、滚轮与键盘导航保留。右键必须在画布内完成一次未拖动的按下/松开；取消、失焦和捕获丢失不下令。目标格下拉框与按钮仍可完成同样操作，不要求使用鼠标右键。

## 路线与时序

- 继续使用真实六邻格和按进入格地形计费的 Dijkstra 路径，不穿越布局空白。普通行军避开当前已知敌军、活动敌城/据点和战事格；进攻或解围只放行明确的目标格，沿途仍避开其他敌对格。
- 下令和预估共用一条路径逻辑。正在行军时先保留当前路段，在其终点接上新路线；预估计入当前路段剩余时间，不重算已走时间，也不把兵旗拉回上一格。
- 停止含义改为“完成当前路段后停止”。取消后续路线、追击、攻城、解围与自动入营意图；不会瞬时驻停在没有逻辑地格的半途位置。
- 每次到格重新评估后续路线。路径被封锁或追击目标消失时停止并说明原因。拒绝新命令时不破坏原命令；玩家仍可另行停止。
- 这是基于当前占格的避让，不是动态敌军预测或绝对安全保证。敌军可能进入已开始的路段终点，届时沿原接敌规则处理。没有新增山河禁行、桥梁、道路、补给或兵种速度。
- 默认基础仍为游戏内半天一格，一天12现实分钟时，现有地貌约需7.2–10.5现实分钟/格。没有调整战争、增兵或AI周期。界面沿原1.2秒刷新展示单枚兵旗、路线、进度和剩余游戏时间，没有新增逐帧全图循环。

## 部队入营与表现

正常目的地扩展为任一已接通的永久建设位面（scene8–scene12），不是仅出发基地。出发基地的快捷返回也走相同的自动入营命令。主神空间保持亲征失败或原基地失效时的原有撤回规则，不成为任意格免费传送入口。

1. 命令记录目标 `sceneId/cellId/worldEpoch`。到格、开始加载、提交目标场景前和加载结束时均核对基地是否仍有效且无战事。重建产生的新世代不接收旧入营命令。
2. 原 `SceneManager` 加载目标建设位面；成功后才调用 `releaseStrategicTroops()`。切场失败走原回滚，保持战略军团及士兵账本，取消自动入营并提示重新下令，不按每秒调度反复加载。
3. 成功后清除大地图我方兵旗，玩家恢复本体；幸存士兵进入目标位面的驻留账本，在玩家落点附近恢复为独立单位并待命。队友按既有驻留规则归入目标位面。
4. 保留身份、血量/法力、状态及原生产来源，不复制回兵营本地名单，不自动转移原兵营人口归属。落点阻塞时沿既有兵线规则保留待物化记录，后续继续尝试。
5. 返回出发基地使用出征时记录的本体位置；进入其他基地使用原场景的记忆位置或默认出生点。此轮没有新增进城动画、兵团展开动画或兵营自动收编。

建设位面与地图战略据点仍是两类对象。攻占一个地图据点不会新增永久建设场景；它可驻足、修复、受到围攻，但不是可自动入营的建设基地。途中接战会取消自动入营，战后需重新下令。

## 存档和修改文件

继续使用战略存档v3，在军团中增加可选的最终目的地、敌对终点许可、入营目标、命令说明和战败标记。旧记录缺少最终目的地时使用剩余路径末格；缺少入营目标时不自动入营。已有路段起始世界时间和耗时继续保存，入营目标恢复后仍检查世代。

| 文件 | 本轮职责 |
|---|---|
| `src/world/strategic-march.js` | 保留当前边的统一路径/耗时预估 |
| `src/world/world-strategy-system.js` | 目标命令、安全路线、到格改令、任意己方基地入营及失败保留 |
| `src/world/world-strategy-campaign.js` | 攻占、追击、解围显式允许敌对终点，战败命令门禁 |
| `src/world/scene-manager.js` | 仅对战略入营追加目标世代/战事复核，复用原切场回滚 |
| `src/ui/world-map-view.js` | 右键识别，沿用当前兵旗/城镇命中区域 |
| `src/ui/world-switch-panel.js` | 共用右键和按钮命令，预计行程、命令状态、入营提示及键盘入口 |
| 本文件、`world-strategy-expedition.md`、`strategic-refinement-2026-08-30.md`、`CHANGELOG.md` | 同步方案、实际行为和交付边界 |
