# 废弃矿洞三级地标路线

> 当前默认已采用[独立探索台v10](dungeon-exploration-console-v9.md)：上方环境、下方独立随机路线。本文记录的贴路模板和容量规则保留给显式旧模式，不再限制默认路线布局。

## 修改边界与回退

- 仅接入废弃矿洞初/中/高级的探索选路页；战斗房生成、波次、怪物池、奖励和钥匙不变。
- 新增十张`assets/scenes/dungeon-map-mine-landmarks/`背景、`src/config/mine-route-landmarks.js`通道模板/展示布局以及生成清单。
- `src/world/dungeon-map-system.js`仅消费矿洞模板；`data/`与`public/data/`三级矿洞配置同步启用地标模式。
- 回退时仅撤销三级矿洞的`mapPresentation/mapBackgroundFullPlate/mapBackgroundVariants/mapBackgroundSelection`，将`mapBackground`恢复`assets/scenes/dungeon-map-bg.png`；这会恢复旧路线显示，恐怖地牢配置不动。模板没有消费者后可删除本次新增导入和文件，不得整文件回退并行会话修改。

## 美术与布局

- 十张背景均由内置ImageGen独立生成，1672×941、固定镜头、冷钢矿洞材质；没有文字、节点、路线、UI烘焙。
- 每张图登记完整的平台中心线`lanes`和楼梯两端`connectors`。塌方绕行图的断裂上层岩道不参与布点或连线。
- 节点候选沿通道按弧长取样；正式展示按实际窗口反投影剔除HUD安全区外位置，并预留徽记、呼吸环与标签边距。基础选图容量保持76源像素，展示为徽记和标签留出至少96源像素间距；低缩放时同时计入屏幕点击缓冲。
- 最多3生成列构成一个区段，密集时根据可见槽位容量提前分段；单列过密也会按节点拆为子区段，每个节点仍有唯一核心归属。接头从真实逻辑邻居选取，优先保留当前位置，超出容量的节点在自身区段查看。不改变逻辑列、房间数、边或可达判定。
- 真实地图边仅在展示时映射到通道/楼梯网络。平台按已登记道路中心线绘制，楼梯复用已登记两端的连线，不再整体旁移；节点后画并遮住线头。共用段归并为只画一次的线束，出口再分开，不设三轨上限；已完成、可前往、不可达沿用原状态规则。
- 绘制、悬停、点击与档案卡入口共用当前可见节点集合；点击时重新命中，不能沿用隐藏节点的旧坐标或悬停ID。切区、总览及窗口缩放清空待处理点击和档案卡。
- 窗口尺寸纳入布局缓存，缩放窗口后重新分区并返回当前位置；极窄裁切没有候选平台时，背景和路线同步平移到最近平台，不移动HUD。
- 单局根据路线拓扑的匹配权重与稳定指纹选一张背景；所有可容纳当前单列负载的模板都有机会出现，返回地图不重新抽取。
- 状态栏、组队栏、收益/入侵、撤离按钮、右侧图标继续复用既有地标HUD合同，不新增布局覆盖。

后续采用“结构先行、图片与通道数据成对交付”的规范，见[路线结构流程](dungeon-route-structure-workflow.md)。当前仍是人工标注的近似模板，撤销偏移不等于所有背景坐标已校准。

## 生成公式与后续复用

1. 每条完整通道弧长为`L`，取`n=max(1,floor(L/(d+6)))`个候选，位置`s_j=(j+0.5)L/n`。选图基础`d=76`；正式展示`d=max(96,76,2r+24/scale)`，其中`r=24`为徽记基础半径。通过实际视窗反投影边界与全体候选间距筛选，得到可见容量`C`。
2. 当前区段`N≤C`个节点选择候选序号`floor((i+0.5)C/N)`，逻辑列从左到右、同列按row分配上下通道；候选互斥。核心区段最多3列、预算`max(1,floor(0.58C))`，单列超过预算按节点拆分，剩余空间容纳真实邻接点。50+房间增加区段数，不持续缩小图标。
3. 通道折点、节点位置与楼梯入口建立展示图，同层同坐标站点合并，Dijkstra只按实际长度选固定通道。按可见节点的完整真实边集缓存几何，而非随悬停/全线显隐重新布线。平台直接使用已登记的道路中心折线，楼梯沿已登记两端连线，不再为避让徽记平移到路外；共线的部分重合也拆分归并，同一边正反向或重复经过只计一次。主干只画一次，不设路线数量上限；多成员用中性冷钢色，独立出口用稳定身份色。`×N`只统计当前显示且实际共段的独立边，混合状态补充可走数量；每屏最多6处标记，同成员只标一次，并避让节点/文字和视窗边缘。悬停可走目标突出完整路径，其它线压暗；箭头放各自目标端。缺少展示路径保留直连回退。重合/交会不新增逻辑通路，也不承诺任意背景或窄窗都完全避开徽记。
4. 背景拓扑差值`D_k=0.34|b-b_k|+0.28|c-c_k|+0.23|v-v_k|+0.15|r-r_k|`，分别对应分支密度、单列负载、同列连接占比与行跨度；通过单列容量门槛后，权重`w_k=exp(-6D_k)`，概率`p_k=w_k/Σw`，用完整路线稳定指纹取样。背景在本局内不变。
5. 新增背景时只登记图片、原始尺寸、完整通道、楼梯、边界和拓扑偏好；不需要修改房间生成器，也不能把断桥或装饰性升降井登记成通路。

生成方式、全部10条完整提示词和原始输出路径见`tools/ai-gen/dungeon-mine-landmark-background-set-20260830.json`。源图保留，正式副本放在`assets/scenes/dungeon-map-mine-landmarks/`；每次只加载本局选中的背景，不预载整套图片。

## 用户验收重点

- 默认简洁连线仅常显当前位置邻接线，悬停节点可补看关联线；“全部连线”可展开/收起，浏览其它区段则保留低对比全线。节点位置及所有已生成路线不应随悬停/开关跳变。
- 4条、6条及更多路线共用平台/楼梯时，主干只描一次，出口有序分开；数量只统计当前显示路线，悬停可走目标能追踪完整路径，箭头不堆在主干中点。重点查看道路中心线与平台的贴合、徽记遮挡、短楼梯、回头路、简洁/全线切换及窄窗边缘；短段或拥挤处允许隐藏数量标记。
- 已访问的可走回头路线与节点也应高亮，箭头从当前位置朝目标。跨区入口显示“可走N”，窄窗口的接头槽位优先当前节点与可走邻居。
- 初/中/高级都进入全屏矿洞路线页；原血魔条大小和位置不变。
- 10种背景与各自平台/楼梯相符，密集岔路、跨区选点及路线返回可用。
- 同一走廊有多条边经过时，重点确认当前银青路线端点仍易辨认；最终线条、标签与徽记避让效果以游戏内为准。
- 手工切区后点击原节点位置/空白处，不得进入未显示房间；旧档案卡不得继续进入节点。
- 缩窄窗口后，当前位置与可选节点应在各自区段内完整显示，切换子区段仍可选择原有邻居。
- 不可达线路保持低对比，可前往与聚焦路线优先显示；同局进入战斗后返回背景稳定。
- 1080p/2K与窄屏裁切、节点点击和悬停档案卡。
