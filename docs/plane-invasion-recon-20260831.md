# 位面入侵：集结、侦察、行军与同族编队

本轮已接入代码，未运行测试、构建或运行时验证，按约定由用户测试。没有启动游戏、同步固定 EXE、提交或推送。并行会话的大地图扩容等修改保留，不列为本轮成果。

## 时间与大地图

- 保留原五日周期与地牢结算推进比例；到原周期最后一天时，在目标基地附近2～3格选择可达空格，生成一枚入侵军旗。
- 军旗及全体编队只存为战略记录，行军期间不创建怪物实体或加载全套动画。基地仍遵守已建门、未毁灭、新生保护和世代匹配条件。
- 入侵军团采用专属急行军：完整初始路线总计1个游戏日，各路段按现有地形耗时比例分配；读取统一世界时钟，不额外推进或加速全局时间。玩家和原巡游军团的行军速度不变。
- 每走完一段才提交占格，检查中间格接触；沿用原军旗途中插值。堵路、拦截、切场等待和目标已有战事可推迟抵达，不穿过占格军团或直接瞬移到基地。没有合适生成点时延后集结，最多每游戏秒重试一次。
- 地牢结算可以提前触发集结；一旦军旗出发，不能用额外入侵进度缩短其行程。出发后新增的地牢进度留给下次集结。旧档即使已到五日阈值，也先获得完整一天的行军阶段。
- 固定只有一个周期性入侵集结/行军槽，上一场周期入侵结束后才进入下一次集结。独立巡游军团攻城仍走原战略战役系统，不被改成同一场入侵。
- 入侵额外保留1个纯数据军旗名额，不挤占原巡游军团与信标守军名额。

## 侦察与预警

| 来源 | 生效条件 | 入侵侦察能力 |
|---|---|---|
| 基地近卫 | 已接通且存活的基地 | 本格；没有免费的远程预警 |
| 普通出征军团 | 在战略地图、未战败 | 周围1格 |
| 斥候军团 | 当前编组有存活斥候、游侠、狙击手或侦察游骑兵 | 周围2格 |
| 天气预测塔 | 本基地存活建筑，至少1个已安排岗位 | 基地周围2格 |
| 位面观测阵列 | 本基地存活建筑，至少1个已安排岗位 | 基地周围3格 |
| 边境侦察条例 | 科技树正式研究，前置“侦察编制” | 所有已接通基地周围1格 |
| 位面预警协议 | 正式研究，前置“边境侦察条例”及“气象预报”对应科技 | 预计抵达前半个游戏日自动发现 |

两项政策位于科技树“军事指挥 → 预警政策”，基础科研成本180/420，实际显示与扣除继续经过现有科研成本曲线。市政政策规划页仍只是模拟，模拟采纳不增加能力、不消费真实科研。

建筑范围取最大值，不按数量叠加；前台读取真实建筑与岗位，后台读取同世代基地快照。撤岗或建筑损毁后停止提供新侦察。侦察源按游戏秒缓存，移动到新格会重新计算；地图范围只枚举来源附近的六边格，不逐帧遍历整张大地图。

未知入侵不会出现在军旗、敌军名册、敌军数量、鼠标指令和路线避敌查询中，顶部也不公开它的时间或目标；同格接触仍然可以触发遭遇。发现后记录来源、家族、编队和预计抵达时间，发送一次通知并加入顶部事件栏及地图动态记录。情报网络此后持续跟踪，离开视野或撤岗不撤销已经发出的警报。

青色地格表示入侵侦察覆盖，地形本身不改成战争迷雾。现有其他巡游军团、信标守军和城镇的显示规则保持。小股侦察通过指挥建筑选择少量士兵出征实现，沿用当前单个亲征军团上限，本轮没有新增自动巡逻小队或多军团系统。

- 甲虫首领在本次入侵中最多额外召唤4只同族幼虫；这4次余量随首领记录保存，幸存幼虫计入剩余兵力、清场和切场。原其他模式的召唤规则不变。直接编队55＋补充4，单次至多59个不同单位先后出场，不代表同屏59只。
- 战略拦截与基地防守使用同一批配置构造器，不附加地牢工厂特有的矿洞等遭遇修饰。怪物自身的已登记视觉依赖仍由原资源管理器处理。

## 战损、后台与兼容

在行军路上击败全军会解除本次基地入侵；中途撤退/战败只留下当前批幸存者及尚未出场的后备。已经消耗的批次、首领和召唤余量不会恢复。抵达后将同一份剩余编队交给基地入侵系统，军旗退出行军账本，不同时保留第二份攻城兵力。

基地前台继续使用正式防守、共享目标寻路/流场、出生避让和资源驻留。后台沿原约10秒窗口，改由新编队真实类型和倍率的兵力摘要聚合结算；保留守军分担、建筑承伤顺序、核心警告和世代销毁事务。后台不逐个模拟技能、召唤或物理，因此仍是近似结算，不承诺与现场战斗一模一样。

入侵存档版本5只新增行军引用与编队记录；战略存档继续兼容已有版本的可选军团字段。地图恢复完成后核对行军引用；目标旧世代军团撤销，不攻击重建后的基地。已经开打的旧档保留原waves及原后台威胁规则，不会重抽或补发新首领。

## 用户重点验收

1. 无侦察时不显示未发现军旗或精确倒计时；有岗观测建筑和出征小队能够发现，同一军团不重复通知。
2. 行军途中存读档、暂停、地牢结算后继续原路径；基地到达只开战一次，不额外推进世界时钟。
3. 中途拦截撤退、下一波前撤退、击败全军后返图：伤势与未出场后备正确保留，全歼后不再攻城。
4. 前后台切场、基地解围撤退及核心毁灭/重建：不重复恢复已死首领，不影响新世代。
5. 两项正式科研生效，政策模拟不生效；建筑撤岗/损毁影响下一支未知入侵的发现。
6. 甲虫召唤后切场或撤退，幼虫仍计入剩余敌军；累计补充不超过4，普通地牢的甲虫技能保持原规则。

已查看本次真实diff及必要局部调用链，未执行测试或运行时验证。首次加入首领和不同家族技能会改变难度；需要用户重点体验初次入侵、首领批次及冷加载。限制种类和出场数量不等于显存硬封顶，实际贴图驻留、帧率和多家族间的难度差异尚未实测。
