# 大地图山脉贴图与战争迷雾

2026-09-01。本文件描述战略大地图自己的山脉显示和战争迷雾。它与scene8～scene11位面内部的`FogOfWarSystem`相互独立：位面内部系统按战场像素网格处理角色视线、遮挡和小地图；战略系统按六边地格处理基地、军团和侦察来源，不能共用128px网格或战场遮挡数据。

> Git发布边界：本次独立分支发布15帧正式山脉图集、双份元数据、可重建来源和本文件的实现合同。下述山脉绘制、战略迷雾及情报过滤已经在共享工作区本地接入，但远端`origin/main`仍缺世界战略底座，无法在不夹带其他会话核心改动的前提下独立发布运行时代码；因此本次提交不表示远端玩法已启用。完整边界见`docs/world-strategy-publication.md`。

## 三态战争迷雾

- **当前可见**：保留原地貌色彩，并以青色细边和浅色填充提示战略视野。敌方移动军团、敌军列表和追击目标只在此状态出现。
- **已经探索**：以半透明灰暗阴影覆盖。地貌和曾发现的固定敌方据点保留，移动敌军离开视野后不再显示精确位置。
- **从未探索**：以深黑阴影覆盖，悬停只显示“未知地格”，不暴露地貌名、敌军或敌方据点。

阴影参数位于`data/world-map-generation.json`。远景使用一张按视野变化重烘的迷雾缓存，近景只遍历当前视口内地格；不会给每个地格创建DOM、Phaser对象或独立贴图。地图格线、选中框和我方战略标记绘制在阴影上方，避免失去基础操作反馈。

## 视野来源与持久化

`StrategicMapIntel`复用位面入侵侦察系统的真实来源与半径：

- 已定位的位面信标至少永久揭示其入口格。
- 玩家基地默认看见基地格；完成边境侦察条例后使用配置的基地视野。
- 有岗位且存活的天气预测塔提供2格视野，位面观测阵列提供3格视野。
- 出征军团和分遣队通常提供1格视野；编有斥候时提供2格视野。
- 移民队和已建立的新城使用各自配置的侦察半径。

当前可见地格会合并进`state.mapIntel.exploredCellIds`。记录携带`worldMapInfo().key`，地图种子或布局变化时不会把旧地图坐标误套到新地图。现有战略存档版本保持5，旧存档缺少`mapIntel`时会从已定位信标和当前侦察源初始化，不删除军团、基地、路线或事件。

敌情显示与玩家路线均使用已知情报：大地图列表和图标过滤不可见移动敌军；普通下令、行程预估和补给线路不会为了躲避未知敌军而泄露其位置。真实接触、拦截和战斗仍读取完整战略状态，因此未知敌军可以在行军途中造成遭遇。已开始追击的目标离开视野后，军团走完当前路段并停止追击。

## 山脉贴图

正式图集`assets/ui/world-map/mountain-relief.png`为1024×812，共15帧、五类位面各三款。`data/world-map-relief.json`保存紧裁区域、脚点、55°正交相机、123.0769像素/世界单位的共同标尺，以及山脊1.35、雄峰1.42、山口1.28的垂直高度倍率。

- 山口地格固定使用对应位面的`pass`模型。
- 其他山地按q/r坐标稳定选择`ridge`或`massif`，不消耗游戏随机数，也不会在刷新时跳变。
- 高度在Blender原生几何中调整，水平占地和脚点保持不变；山口只增高两侧山体，中央通道宽度不变。
- 远景将山体烘进地貌缓存，近景按可见地格绘制；运行时只加载山脉图集，不常驻17个尚未接入的河流候选。
- 正式山体只替换视觉符号。山脉不可通行、山口可通行、河流跨越耗时等规则继续以战略地形数据为准。
- 图集加载失败时恢复原矢量山形，不阻断地图选择、移动或基础地貌加载。

## 验收重点

1. 新局和旧存档打开大地图时，基地/信标附近可见，远方为深黑；移动后旧视野变为灰暗探索区。
2. 普通军团、斥候、天气预测塔、位面观测阵列、边境政策分别产生配置半径，重叠视野无接缝。
3. 敌军进入视野时出现在地图与列表，离开后图标、列表项和持续追击一并结束；入侵预警事件仍保留。
4. 五类山地均使用对应材质，普通山脉稳定选款，山口使用开阔通道模型；近景和远景脚点一致。
5. 缩放、拖动、地形耗时镜片和地图重开不造成迷雾闪白、山体跳变或隐藏敌情泄露。
