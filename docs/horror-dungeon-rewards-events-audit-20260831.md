# 恐怖地牢 C/B/A 奖励、事件与经验审计

日期：2026-08-31。范围仅恐怖地牢三档，以及其奖励配置所需的共用读取接口。已阅读近5次提交、CHANGELOG、SKILL第06卷奖励/事件合同及上一轮怪物审计。以下为源码、配置和数学推导，不是游戏实测；未运行测试、lint、构建、浏览器或EXE。

## 发现与处理

1. 恐怖限定事件仍分散于F/E/D/C/B，A级只能抽到一个B级镜面事件。现将原15个事件重排为C/B/A各5个，不新增背景、不改其他系列、不另写抽取分支。
2. 事件金币虽已按当前C/B/A的×6结算，但部分基础金币、材料、固定药量仍是新手数值。现逐项修改30个属性检定的成功与失败，以及15个无检定结果；不把材料收益机械加给所有选项。
3. 诅咒板甲刷精英骑士却标为普通战，部分事件写单波但实际会扩成3/5阶段。现明确普通3阶段/精英5阶段及逐阶段配比，骑士改标精英；强制怪保留在末阶段，不让领主每阶段重复生成。
4. 通关仍使用剧情通用卡：普通卷轴+200粉尘、2石/2券+1000金，保底武器也不分档。恐怖系列现使用独立C/B/A通关预算；其他地牢和剧情卡不变。
5. 恐怖推荐40–55/55–70/70–85级，却用12/15/18比较击杀经验，推荐起点玩家已落入1%/3%/5%/10%的普通/精英/领主/Boss衰减下限。新增43/58/73经验比较锚点，只供恐怖击杀经验使用；战斗属性仍沿上一轮12/15/18成长和恐怖专属倍率，不重新放大血量、伤害。
6. 恐怖经验预算和路线预览原先少算竞技场末段补到10只的普通怪。现把普通遭遇计为20普通+1精英，精英遭遇计为26普通+4精英+1领主；独立Boss不套此补齐。

清剿奖每个路线战斗节点结算一次，不是内部每个阶段都领一次。C/B独立Boss遭遇走CombatRoomSystem的Boss金币；A级集合体走BossRewardSystem的Boss金币，不再额外叠加一次普通清剿金币。怪物击杀金币、Boss击杀掉落、宝箱和事件收益仍独立存在。

卡牌标题/图标沿原三选一界面；内容和奖励计划同一对象。固定武器品质文本与实际过滤使用同一稀有度列表。完成、取消与异常清理恢复原卡牌，下次普通任务的武器选项也重新初始化，不带出恐怖奖励。

### 实际事件池与遭遇

- 通用事件30%、限定事件70%、同题材±1级规则不变。C实际池=C5+B5，B=C5+B5+A5，A=B5+A5，分别10/15/10种。因此相邻等级的材料、检定和风险也可能出现；战斗怪物成长及金币倍率仍按当前地牢。
- 保留原有三个叙事伏击：鲜血祭坛、深渊赌徒、幻影镜面。原始C/B/A事件各有0/1/2个危险末项；在实际限定混合池中分别为10%/20%/30%。这不是所有事件遭遇的战斗概率，也不套用雪原专属80%规则。
- C普通事件战实际为20普通；牢房末段两只强制普通怪不占10只普通增援目标，实际总22普通。B普通事件战为20普通+1精英。A级镜面为19普通+2精英。
- B板甲战为26普通+4随机精英+1强制骑士。A赌徒拒绝战为26普通+4精英+1领主；军械库、管风琴、标本库再有1只末段强制精英。领主只在末段，未复制到前四段。
- 每个战斗结果显式给3/5段配比，强制怪工厂均在现有21种恐怖怪物范围内。事件只覆盖配波，怪物池沿原节点转换继承当前地牢，不抽入矿洞/雪原/沼泽怪。属性选择的描述已提示失败会进入几阶段战斗；三个无检定伏击保留原叙事反转。
- 墓碑、巫婆煮锅、巫师/蝇手/集合体召唤、时空特工仍可叠加实际战况，不据表格承诺整局固定怪物总数。

## 经验与整条路线预算

- 恐怖经验比较锚点43/58/73继续加配置等级−3的种间偏移。角色在40/55/70的推荐起点且怪物配置等级3时，比较差为−3，倍率1；原来三档都已达到压级衰减下限。越级加成、超出锚点5级后的衰减、连战、祭品经验加成仍沿原机制。
- 12/15/18仍是战斗属性成长锚点。不要将新经验锚点回填Enemy属性构造器；否则会重复放大上一轮的恐怖数值。21种生命/攻防表仍见上一份怪物审计。
- 普通/精英事件及召唤并非固定路线，不能把全部事件奖励和怪物掉落相加当作必得。经验预算保留原pacingRuns=5、exploreFactor=0.8、清剿份额30%，只将恐怖正规竞技场漏算的末段普通增援纳入；路线期望仍是配置估计，不是随机种子的实测总量。
- 同一路线结构下：总金币=节点清剿+怪物掉落+Boss奖+通关基础+所选卡牌金币+实际宝箱+事件净金币。材料和装备应单列，不强制折算出售价格。

例：仅取4个非Boss战斗节点、1次Boss和一次通关，选择强化或改造卡，不含任何怪物、宝箱、事件金币，则C为22400–25400金，B为36200–41800金，A为55300–63700金。该例不是最短路线承诺，也不是每局固定收益；它让同样节点数的基础奖励能横向比较。

银行的同时间窗收益读取PopulationEconomySystem.getBankSnapshot：有效服务人口×每人口金币×职员数×劳动效率×工坊倍率×酒馆倍率÷结算秒数。没有进入游戏读取用户银行或测量路线耗时。若把上例放进纯假设的15分钟窗口，地牢已知部分分别约24.9–28.2、40.2–46.4、61.4–70.8金/秒，另有战利品；可与当时银行HUD实际金/秒比较，不能据此宣称已超过用户当前所有被动产业。
