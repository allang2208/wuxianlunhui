# 2745格随机大陆与分层性能实现

日期：2026-08-31。范围：新局大地图生成、存档地图身份、地图绘制与战略行军调度。未运行测试或运行时验证，按约定由用户测试；未构建或同步固定EXE。

## 本局地图如何生成

- 默认2745格，正好是原305格的9倍面积，并非长宽各扩大9倍。
- 新游戏在 `Game.start()` 的加载阶段读取独立随机种子，在位面入口初始化前激活地图。地图面板重开、切换基地和继续读档都不重新抽图。
- 算法使用旋转/拉伸后的径向距离叠加两层平滑噪声，按相邻前沿逐格扩展连通大陆，直到达到指定格数。所有新增格都与已有陆地相邻。
- 选取五个分散地貌起点，打乱沙漠、雪地、森林、遗迹、矿区的对应关系，再用带噪声代价的多源扩展生成连续地貌区。地块变体由种子与坐标选取；仍使用现有50个图集变体和55°镜头契约。
- 战略随机流从地图种子独立派生，新局据点分布也随之变化；不消耗战斗随机流。敌军上限和每个位面的城镇/据点数量保持既有配置，没有随面积乘九。
- 地图标题显示本局格数，悬停可查看种子。坐标输入接受 `-12,8`、中文逗号或空格分隔，按Enter/定位按钮选择并居中；不会自动下达移动命令。

## 存档与旧版兼容

- `worlds.map` 单独保存地图版本、种子、生成器版本，以及实际 `[q,r,biome,tile]` 地块数组。尚未出征时保存也会保存地图。
- 读档先准备并核对地图记录，再替换当前地图；无效版本、重复/越界坐标、无效地貌/贴图和缺失地貌会拒绝载入，不悄悄生成新图顶替。生成器以后升级也不会改变已存地图。
- 地图先于位面入口、基地、兵力及战略路线恢复。读档切换期间暂停战略调度并清除旧到达队列，避免上一局事件在新地图生效。
- 没有 `worlds.map` 的旧档继续使用原305格静态布局，保留原坐标和部署；要体验2745格需开始新游戏。旧档重新保存也保留旧版地图身份。
- 不同地图清除旧格选择和镜头历史；同一地图重开保留镜头，图层/格线偏好继续共用。

## 性能边界

| 部分 | 当前实现 |
| --- | --- |
| 战略地块 | 只有坐标、地貌、邻接等轻量记录；不为2745格创建场景、单位或物理对象 |
| 近景 | 按16世界单位分块查询视口和贴图边缘范围，仅排序、绘制相交地块 |
| 远景 | 使用地貌/地形耗时两张有尺寸上限的缓存；低于18像素尺度或视口估算超过1000格时启用，放大后恢复细节和格线 |
| 缓存建立 | 每帧最多96格并采用3ms软预算，先铺地面再按深度绘制地貌；面板销毁取消任务并释放画布 |
| 内存约束 | 远景缓存每张最长边1536像素；主画布和兵棋画布沿用各400万像素上限，不建立整张地图的高清巨图 |
| 寻路 | 二叉堆A*；没有可用下界的通用调用保留Dijkstra。六邻接预索引；最多128条条件相同的路径缓存 |
| 缓存条件 | 地图修订、起终点、地形成本、敌方占格、最终攻击例外均参与；只缓存路径，当前段剩余时间每次重新计算 |
| 行军到达 | 到达事件按时间堆排序；单帧最多64项及3ms软预算，剩余工作下一帧继续，逐格处理遭遇/入营，不瞬移跳过中间格 |
| 远方决策 | 已在行军的军团不每帧寻路；普通远方闲置/受阻军团10秒重试，接近玩家或完成路段时及时决策，命令变化也使旧等待失效 |
| 后台世界 | 沿用已有基地/生产/围城数值结算；只有实际进入的位面或战斗物化。镜头移动不会暂停或加速远方行军 |

这里的3ms是批次之间检查的软预算，单次寻路或事件本身不可被中途截断，不承诺任何机器上的固定帧率。没有启用Worker并行模拟，没有增加全图逐帧实体扫描。入侵军团仍走现有专用行军协议和倍率，本轮不改其玩法。

## 保留的玩法与已知限制

- 仍是五类建设位面；2745个战略格不等于2745个常驻建设场景。
- 保留地形加权、已知敌方中间格避让、当前已开始路段、Shift途经点、追击、接触战斗和己方基地自动归营；不改唯一兵力账本。
- 逐格速度仍为0.5游戏日乘地形倍率。地图更大带来更长的跨图总行军时间，等待节奏须根据实际体验另行调整，不能只给玩家暗加速。
- 本轮大陆地块均可通行，仍无河流桥梁、不可通行山脉或渡海规则。这些属于后续地形挑战设计，不混入本轮扩容。
- 2745格生成在新游戏加载阶段完成；首次打开地图会分帧补齐远景地貌。生成耗时、首次显示、缩放边界和实际帧率尚未实测。
- 新版地图存档需要本轮代码读取；尚未同步的旧固定EXE不具备这些地图字段的恢复逻辑，不应用于读取新图档。

## 用户验收重点（尚未执行）

1. 连续开始两次新游戏，应都显示2745格，种子与轮廓、地貌、据点布局不同。重开面板/切换基地不能重洗地图。
2. 保存新局，重新启动并读档，核对地图种子、基地坐标、据点和部队位置一致；再读旧档应恢复305格。
3. 地图拖动缩放、远近景切换、格线/耗时图层、坐标输入（含负数与中文逗号）、鼠标命中与兵棋位置应一致；关闭面板后不继续烘焙远景。
4. 长路线与Shift多站、行军中改令/暂停/保存读档：已开始路段不重置，预计时间持续扣除，已知敌方中间格仍避让。
5. 沿路接敌应逐格触发；进入己方基地后本体与幸存部队正确归营，不复制或丢兵。跨基地调兵与归营回执沿原协议。
6. 远方军团仍按共享时钟移动与围城；镜头靠近/离开不改变到达时间。大跨度推进时间时到达队列分帧追赶，不能跳过遭遇。
7. 性能和不同随机种子的覆盖测试需另行明确授权后测量；本轮只查看真实差异和完成实现必需的局部调用契约，未运行测试、lint、类型检查、构建、浏览器/游戏或性能探针。
