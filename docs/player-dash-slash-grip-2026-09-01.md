# 普通冲刺攻击：下劈轨迹与逐帧抓握

沿用三段普攻的同帧抓握方法，调整普通冲刺从后上方提剑、越顶、向前下劈和低位收势的显示。只处理普通冲刺 `dash_attack/dash_recover`；骑士长剑专属冲刺突击、三段普攻、奔跑及防御不改。

## 改动

- 原人物17帧、旧剑轨迹30点独立插值，角度再固定按−90°→90°匀速扫过。本次新增 `sword.dashGrip`，以实际人物帧读取17组真实掌点、刃向和模糊，不让武器在静止手内继续沿插值曲线滑动。
- 重新区分提剑、越顶、回砍、收尾：角度−90、−84、−76、−65、−58、−51、−44、−35、−27、−18、−3、28、69、94、98、97、96度。末端掌位接近地面，剑身以接近水平的小幅回收结束，不把低手位的剑尖大幅插入地面。
- 四剑按各自 `textureGrips` 绑定，默认尺寸1.5、拉伸1，模糊峰值3。原生主手前景覆盖剑柄；源帧4/5的张手用相邻源帧3的闭拳切片收拢，保留原肩、肘、腿及身体轨迹。
- 清除源帧14/15身体之外的旧烘焙弧线，避免与新剑轨迹交叉。只写衍生图集，不覆盖原始PNG。
- 携盾奔跑的前120ms沿用已确认过渡图，剑柄改读真实贴图原点，过渡角度接向新17帧轨迹；仍覆盖既有8种跑步入口，不重新生成或延长起手。空副手保持原生起手，接入相同17帧握点。
- 定格及收势首帧复用下劈末帧的身体、掌层、剑盾位置。后续逐帧回手，收势张手复用已确认的握拳切片；旧手遮住的少量腿部延续线只在清除手的局部遮罩内补回，未改变腿部姿态。
- 回待机末帧使用已确认的待机身体/握拳。携盾回跑最后4个显示帧复用已有回跑过渡并接原第3跑帧；保留移动取消收势的规则，不强制玩家看完新过渡。

## 代码、配置和来源

- `src/phaser/player-sword-shield-motion.js`：新增 `_syncDashGrip`，在现有物理同步后统一放置身体、主剑、掌层与盾。下帧归还原纹理/缩放及手层可见性；排除突击、死亡、翻滚和Canvas路径。
- `src/phaser/scenes/BootScene.js`：预载普通冲刺的两页图集。文件中的其他并行会话内容保留。
- `src/ui/dev-tool.js`：普通冲刺按17帧显示和编辑 `dashGrip`，预览默认800ms，手动FPS仍可覆盖；重置回本次标定，保存沿现有全量配置接口。与三段普攻共用握把计算，不再经过会把未知块名回退为attack的旧逐帧导出接口。
- `data/weapon-anim-config.json`、`public/data/weapon-anim-config.json`：只增加 `sword.dashGrip`；保留 `dash/dashHand/dashLerp/dashThrust`、三段Grip及其他状态。
- `data/player-dash-slash-grip.json`：源尺寸、31个攻击/收势姿态引用、默认17帧及回跑采样表。直接JS导入，无public副本。
- `assets/player/dash-slash-grip/slash-0.png/json`、`slash-1.png/json`：两页2018×1896、2048×1333，60个身体/掌层切片；收势首帧复用攻击末帧。保留各自512×516、512×512或516×516源空间，紧裁不改变显示比例。
- `tools/animation/player-dash-slash-grip-20260901/`：可编辑的掌点/腕点、局部遮罩、制作脚本、源参考及离线预览。仅复用原生dash、已确认的跑姿过渡、待机与握拳切片，没有新视频或模型生成。

伤害、技能等级收益、命中范围/窗口、音效、冲刺方向、位移、800ms攻击基准、500ms定格及500ms收势规则均未修改。`dash-system.js`、GameScene、player-anim-config及combat-config本轮未编辑。新轨迹是显示层覆盖，旧配置继续保留给既有非剑/兼容路径。
