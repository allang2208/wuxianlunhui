# 地牢墙壁/地板风格基准评估（2026-08-11）

> 结论先行：**材质视觉基准 = 僵尸地牢（default 深色砖石）；新地牢管线/结构基准
> = 沼泽地牢（swamp 样式）**。实际做法：结构照抄沼泽、材质照抄僵尸——新地牢 =
> 复制 swamp 的样式注册骨架（corners + 通道预制 + 宝箱房预制 + 门音效），贴图以
> 深色砖石为底做主题改色/叠加。

## 1. 两套墙样式的资产结构（ISO_WALL_STYLES 登记点）

| 维度 | 僵尸 default | 沼泽 swamp |
|---|---|---|
| straight 键 | `straight`（wall_straight.png） | `swamp_straight`（swamp_wall_straight.png） |
| gate 键 | `gate`（wall_gate.png） | `swamp_gate`（swamp_gate.png） |
| 转角 | **无 corners 登记 → 程序化转角臂**（wall_corner_*.png） | **登记 corners**：沼泽上/下/左/右夹角（swamp_wall_straight+swamp_gate 预制拼装） |
| 通道预制 | 左右通道 / 上下通道（通用） | 左右通道·沼泽 / 上下通道·沼泽（专属） |
| 宝箱房预制 | 宝箱房（通用） | 沼泽宝箱房（专属） |
| 门音效 | gate.mp3（通用） | swamp_gate.mp3（专属） |

沼泽是 style 系统里唯一把「四角预制 + 通道预制 + 宝箱房预制 + 专属音效」**全套配齐**
的样式——新增地牢照这个骨架登记，几何零返工。

## 3. GLM-4.6V 视觉定性

- **wall_straight**：规则砖石、深黑灰、阴森压抑；**通用性强**——砖石基础结构可
  通过改色（冰窟冷灰蓝/火窟暖棕红/神殿浅灰）+ 叠加主题元素（霜冻/熔岩/符文）适配
  任意主题。
- **swamp_wall_straight**：枯枝杂草自然材质、腐朽荒芜；**通用性一般**——只适配
  沼泽/废弃森林类主题，冰/火/神殿不匹配。
- **blackbrick5**：规则斜向石板网格；**高度通用**——改色即可承载各类主题。
- **swampbrick-new1**：苔藓/草皮覆盖石板，细节足；**偏自然风**，沼泽/森林最合适。

## 4. 结论与理由

### 为什么材质基准用僵尸地牢（深色砖石）
1. 贴图是这套体系里唯一"可换层"（SKILL 训练结论：几何是确定性数据层，贴图是
   唯一值得训/换的部分）。生成别的迷宫 = 换贴图。
2. 中性深色砖石（亮度 21.6、低饱和）是**最好改色的底**：加蓝=冰窟、加红=火窟、
   调浅+雕刻=神殿；沼泽的绿苔/枯枝是强主题色，洗掉才换得了主题，成本高易脏。
3. 地板斜率标准本来就锚定在僵尸地牢：FLOOR_SLOPE 注释「实测 blackbrick 29.7° →
   标准 30°」——项目的地板几何基线早已是僵尸这套。
4. blackbrick 的斜向石板网格是模块化骨架（18% 砖缝 + 深底），改色即任意主题地板；
   要更高细节就在网格上叠加主题贴图（冰纹/熔岩纹/符文），网格骨架不会锁主题。

### 为什么结构基准用沼泽地牢（swamp 样式）
1. 新地牢在 `ISO_WALL_STYLES` 登记；swamp 是**唯一完整演示**该登记模式的样式
   （corners + 通道预制 + 宝箱房预制 + 专属音效），default 的转角还是程序化臂。
2. 迷宫/竞技场的转角、通道、宝箱全部有沼泽专属预制——复制这套骨架 + 换贴图键，
   新地牢自动获得完整几何。

## 5. 落地建议（给以后的地牢生成）
1. 复制 swamp 注册骨架：`ISO_WALL_STYLES.<新地牢> = { straight, gate, chestPrefab,
   corners, gateSound }`，配 4 角预制 + 左右/上下通道预制 + 宝箱房预制。
2. 贴图生成：以 wall_straight / blackbrick 深色砖石网格为参考图（img2img / 深度
   模板），按主题"改色 + 叠加主题细节"，走 wall-asset-prep.py + 像素/GLM 验收。
3. 验证沿用 SKILL 2.4《地牢迷宫自动生成关键参考》的 CDP + GLM 方法论。
