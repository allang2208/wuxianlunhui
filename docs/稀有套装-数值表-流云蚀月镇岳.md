# 稀有三件套 + 独立首饰 数值表

> 稀有度：**稀有（rare）** ｜ 规则：属性与强化成长 = 对应**优质（uncommon）**基准 × **1.25**，取整向上
> 结构：**三套独立三件套**（头盔/护甲/靴子，三件齐穿触发各自套装效果）+ **三件独立首饰**（不参与套装）
> 命名：轻甲套「流云」、法袍套「蚀月」、重甲套「镇岳」；首饰：星陨之戒 / 不息腰带 / 磐心项链
> 命名参考：暗黑3中文本地化意象命名（流云月华/时光流韵）与艾尔登法环月主题（月隐/暗月）。

|---|---|---|
| 轻甲 | +10% 移动速度 | 移动速度 **+15%**、体力恢复速度 **+12%** |
