# 大地图途经点与路线编辑

2026-08-31，接续用户“继续”。本批完成既有待办中的Shift右键途经点、编号预览、队列累计耗时与删除后续节点；没有调整行军速度、战斗强度或部队迁移。

## 使用方式

| 操作 | 结果 |
| --- | --- |
| 普通右键目标格／底部原下令按钮 | 替换未执行计划；当前正在走的路段仍须完成。普通右键我方兵棋仍为选择。 |
| Shift＋右键／底部“追加路线” | 保留现有终点作为途经点，再追加所选目标；无计划时直接建立第一站。 |
| Shift悬停 | 显示追加后的整条预览、站数及总耗时；光标徽记附加“+”，原鼠标热点不变。松开Shift恢复普通重排预览，无需移动鼠标。 |
| 侧栏“行军路线”中的地点 | 定位该站，复用上批镜头返回记录。地图编号本身也可选中对应地格。 |
| 中间站“在此结束” | 保留到该站的计划、删除之后全部节点，并取消尾部攻击或入营；该站改为待命终点。 |
| 停止行军／到下一格停止 | 取消全部未执行计划，若已在路段中则抵达下一格后停止。 |

最多8站，包含终点，配置为 `data/world-strategy.json → march.maxRouteStops`。不重复追加当前终点，允许明确的非相邻重复地点形成往返路线。地图同一地格多次经过时合并编号，例如“1·3”；侧栏保留逐站独立顺序，经过一站后重新编号。

普通行军后可以把追击、攻城、解围或入营追加为最后一站；攻击/入营之后禁止继续排队。接战后需要重新下令，不在战斗或部队入营之后自动执行旧计划。明确摧毁仍沿原独立按钮，普通/Shift右键不会自动选择摧毁。

## 路线、时间与生命周期

- `strategicRouteEstimate` 按指定站序逐段调用原地形成本六邻格寻路，返回扁平实际路线及逐站累计游戏时间。显示与执行共用估算器；各段本身最短成本，但不会擅自改变玩家指定的站序。
- 追加、重排及删除都先完整估算，通过后才修改军团。任一段不可达、已有终点不能续接、超站数或重复终点时保持旧计划。攻击目标的敌占格豁免只在最后一段有效，前面的途经段不得为“抄近路”提前穿过敌城/军团。
- 既有当前路段保留 `from/to/startedAtGameTimeMs/durationGameMs`。下一段最早从 `routeIssuedAt` 开始，补算不能把下令前已流逝的时间用于新路线。累计预估包含当前路段剩余时间，不重置进度，也不改变世界时钟倍率。
- 地格到达时按顺序消费中间站，并沿原到格逻辑复核敌占格、追击位置、战事与基地世代；无法继续时停止并清空后续节点。已开始路段仍可能遭遇移动敌军，队列不提供安全通行保证。
- 实际接战时清空全部后续节点，沿原遭遇战生命周期处理；入营只在路线和途经点都完成后触发。途经其他基地不迁移部队。成功入营仍沿唯一携军账本、原生产人口来源与接收清单处理。
- “在此结束”提交时核对军团ID和完整站序，防止世界时间继续推进、列表刚变化时截错节点。删除后仍需经过原命令准入和完整路线估算。
- 沿战略存档v3保存可选 `army.waypoints` 和 `routeIssuedAt`。旧档缺少途经点视为无中间站，保留原路线；无效/超长途经点计划整体取消，但保留已校验的当前路段和全部兵力。读档之后依旧按原逻辑复核动态占格及基地，不伪造旧计划成功。

## 展示与边界

地图编号在原兵棋透明层绘制，随相机缩放/平移刷新，不新增世界实体或独立模拟时钟。列表显示各站累计游戏时间；底部区分“重新规划”与“追加后”的估计，避免把直达耗时误作整条队列耗时。地图图层、军旗原图、已有动画与减少动态效果设置保持。

复用原冷钢徽记，只添加UI“+”标识；未生成或替换新的位图资产。侧栏定位/结束按钮至少44px，键盘焦点沿现有刷新保留机制；Shift监听与地图关闭时的AbortController一起释放。未新增提示音，本批不处理整体行军节奏。

## 交付与人工验收

已查看本轮开始快照后的真实diff，并核对必要的命令—估算—行军—接战/入营—读档局部接线；没有开展全局扫描或处理并行会话修改。

**未运行测试或运行时验证，按约定由用户测试。** 未运行lint、构建、开发服务器、游戏、浏览器/CDP或截图对比；未同步EXE、提交或推送。因此代码已接入不代表路线行为和窄屏显示已通过游戏验收。

重点人工场景：

1. 普通下令A，Shift追加B/C；预览、地图编号、侧栏与实际经过顺序一致，底部累计耗时包括中间站。尝试同终点和第9站时旧路线不应变化。
2. 跨格中追加或截断，当前旗帜不回跳、当前进度不重置；普通右键重排和停止都清掉后续计划。当前段已计时完成但尚待下一次结算时编辑，不应得到新路段的免费进度。
3. 安排中间站再追加己方基地，经过中间站时不入营，最终沿原迁移协议入营；追加攻击终点后不允许再追加。敌方最终目标不能被前方途经段提前穿越。
4. 途经点附近出现新敌军、基地毁灭/重建、追击目标消失、提前接战时，计划按原安全边界停止或取消；战后不自动续行旧队列。
5. 在某站“在此结束”，检查后面的攻击/入营动作也取消。列表刚消费一站时点击旧按钮，应拒绝过时站序而不是截错路线。
6. 中途保存/读档保留站序与当前段进度；没有新字段的旧档仍正常加载。关闭重开地图后Shift不粘住，键盘追加按钮、缩放后的编号点击及窄屏列表可用。
