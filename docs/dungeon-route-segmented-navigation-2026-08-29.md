# 地牢长路线分区展示方案（2026-08-29）

## 目标

僵尸家族地牢当前配置已达到约 45～70 个节点。路线界面不能把所有房间持续缩小到同一张图里，也不能因为显示优化改变房间生成、迷雾、双向可达、奖励、入侵或节点完成逻辑。

本轮采用“语义缩放”展示：

- **路线总览**只显示区段摘要，用于理解整次远征的长度、当前位置和整体进度。
- **区段聚焦**显示当前区段的真实节点，并额外保留前后各一列作为连续路线的接头。
- **当前区自动跟随**在进入新房间并返回路线页后自动切到玩家所在区段；手工查看其他区段不改变玩家当前位置。
- **分区导航**使用原生按钮，提供上一段、下一段、路线总览和聚焦当前位置；节点选择仍走 `isNodeClickable()` 与 `_enterNode()`。

## 分区规则

- 按生成器的 `node.col` 划分，每 4 列为一个区段。
- 同列宝箱岔路归属同一区段，不改变岔路入口、长度和往返边。
- Boss 与奖励节点自然落入最后区段，不建立第二套路由数据。
- 区段摘要只公开房间数量和探索数量；节点类型仍受既有迷雾规则约束。

## 视觉规则

- 总览为冷钢地标链，不绘制几十个微型节点。
- 聚焦态的节点、连线和状态颜色继续消费现有冷钢语义；可达、当前、完成、迷雾状态不变。
- 分区按钮显示“查看中的区段”和“玩家所在区段”两个不同概念，避免浏览其他区段时误以为角色移动。

## 回退说明

区段聚焦与 DOM 路线栏属于表现层，初始化异常时必须自动切换为完整基础路线图；异常不得向上打断 `DungeonMapSystem.init()`，也不得阻断出征流程设置 `scene7`。

如需回退本轮长路线展示，移除 `dungeon-map-system.js` 中的路线分区/总览辅助方法和 `routeViewMode` 状态，恢复 `_fitRouteMap()`、`_focusOnCurrentNode()` 与 `render()` 直接绘制全部节点；同时删除 `panel-theme-backpack.css` 中 `.dungeon-route-sector-*` 规则。底层节点和边数据无需迁移或回滚。
