# 地牢免钥匙调试

入口：T开发面板→技能→无限资源右侧的“地牢免钥匙”。独立于无限资源，默认关闭，状态不保存到存档。

- 开启：不要求持有对应等级钥匙，也不扣除背包/仓库钥匙。
- 关闭：沿原背包优先、仓库其次的持有检查和扣除规则。
- 地牢解锁、资源登记与其他现有出征条件不变；不影响钥匙交易、合成或祭品消费。
- 出征说明随按钮切换刷新；载入等待之后重新读取开关，成功提示与实际扣费状态一致。

公共判断位于 `src/config/dev-cheats.js`，按钮位于 `src/ui/panels/dev-tools.js`，出征持有检查/扣除/说明位于 `src/ui/expedition-system.js`。隔离发布只迁入上述功能代码块，不带入其他任务的导航与世界出征重构。

未运行测试或运行时验证，按约定由用户测试；重点验收开关前后、无钥匙入场、不同等级地牢及正常模式扣除。本轮未构建或同步EXE。
