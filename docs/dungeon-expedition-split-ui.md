# 地牢远征组合界面（2026-08-30）

> 历史过渡方案，当前默认已为exploration v10；见dungeon-exploration-console-v9.md。下文不代表当前默认。



## 本轮采用的方案

默认启用`mapLayout: 'split'`：中央可用区域上方36%展示环境，下方64%提供独立探索路线。图片只负责氛围，不再限定随机房间图的道路与分叉；不接入识图模型，不生成新背景。

沿用左侧情报/组队、顶部原尺寸血魔条与右侧入口的地标HUD安排。路线区预留左274px、右104px，内部左右再留16px；导航仍是区段、全部/简洁连线、战略总览和返回当前位置。退出地牢移除组合版body类，不把样式带到战斗和世界界面。

## 路线排列和交互

- `src/ui/dungeon-expedition-layout.js`只读真实节点/边，生成独立展示坐标。按逻辑列排列，列距220、同列节点距100；初始顺序沿用row，通过四次左右扫描，仅接受能减少相邻列连线交叉的换序。
- 排序使用完整逻辑图并缓存，悬停、切区与背景切换不重排节点。列间使用短水平出入口加直线，避免汇成贯穿整列的大总线；同列连接走列侧。精确重合片段仍交线束渲染器去重，不承诺任何图都完全无交叉。
- 每区根据路线窗口宽度显示1～4个核心逻辑列，保留前后接头列。正式节点不因50～70房间而无限缩小；聚焦缩放0.95～1.2，容纳不下可拖动。总览保留分区摘要与入侵者位置。
- 当前位置真实邻接线常显，悬停补充关联线，全部连线可以展开；继续保留相近色、可走目标箭头、完整路径聚焦、档案卡、双向回头路和`isNodeClickable()`进入门禁。
- 画线、徽记、命中、档案卡、入侵者与返回当前位置共用展示坐标。背景不随路线拖动；窗口改变清理旧指针状态并重新聚焦当前区段。

## 接线与保留项

- `src/config/dungeon-config.js`统一默认布局；只读`getMapLayout()`避免逐节点深合并完整战斗配置。各地牢当前JSON无须批量改写。
- `src/world/dungeon-map-system.js`接入分区、环境展示、布局缓存与旧交互。现代图标/配色仍使用现有资源与主题，图片变体按路线指纹在本局选定一次。
- `ui/panel-theme-backpack.css`添加组合版底部导航与较窄窗口的两行排列；不修改原血魔条、组队成员卡或右侧入口尺寸。
- 房间生成器、怪物、奖励、入侵规则、迷雾、存档协议都不变；背景、旧地标通道数据与此前贴路实现全部保留。
- 如需显式恢复旧显示，可在对应地牢配置（`data/`和`public/data/`同步）设置`mapLayout: 'legacy'`，由原`mapPresentation/mapBackgroundFullPlate`继续决定旧分支；本轮未执行该回退。

## 验收与限制

未运行测试、构建、lint、浏览器或运行时验证，按约定由用户测试。没有生成或宣称实机截图。

重点看：首次进入、战斗/事件后返回、跨区回头路、4条及更多分支、简洁/全部切换、拖动后松手不误入、档案卡选择、入侵者位置、总览/返回当前位置、1920/2560与较窄桌面窗口，以及退出后的HUD恢复。

固定左右HUD会压缩极窄窗口的可用空间，密集行可能需要纵向拖动；本轮没有移动或缩小HUD解决手机级宽度。背景在上区等比裁切，具体构图与线条美观度尚待实机确认。旧“图片与道路同源”文档仅适用于仍显式启用的贴图模式，不再是默认探索界面的制图要求。
