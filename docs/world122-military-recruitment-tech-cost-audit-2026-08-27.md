# World-122 军事募兵建筑科技成本审计（2026-08-27）

## 审计范围

- 对象：仓鼠草屋、仓鼠军营、靶场、骑兵学院、教堂五类募兵建筑的 I—III 级科技卡。
- 对照：经济建筑按住房时代递进的建筑解锁/标准化科技成本，以及当前 `researchCostCurve` 的真实折算结果。
- 不改：节点 ID、前置关系、科技布局、占位状态、兵种解锁、建筑造价、募兵速度、兵种数值和科研吞吐曲线。

## 经济科技参考档

| 参考阶段 | 代表节点 | 基础成本 | 折算成本 |
| --- | --- | ---: | ---: |
| 二级经济建筑 | 乳品畜牧 / 主权铸币 / 深钻工程 | 170—180 | 260—270 |
| 三级经济建筑 | 面包烘焙 / 综合商业 / 风力发电 | 300—320 | 600—640 |
| 四级经济建筑 | 连锁餐饮 / 资本市场 / 光伏发电 | 520 | 1560 |
| 五级经济建筑 | 分布式算力 / 位面谐振 | 780 | 3510 |
| 六级经济标准化 | 算力标准化 / 谐振校准 | 920 | 4140 |

募兵建筑一次换代会同时提升建筑等级并替换两条生产槽，价值高于普通早期建筑解锁。因此二级取四级经济建筑档，三级取六级经济标准化档；不再使用与经济时代脱节的 10→1500→9900 断崖。

军事组织及各建筑的初始建制/兵种专精基础成本为60—190、折算后60—290，与二级经济建筑260—270点的早期开放区间相邻，且承担初始建筑或基础兵种门禁，没有重复断崖，因此本轮保持不变。军械库和战地医院属于军事支援，不是三级募兵换代，也继续保留各自150—360点的早期功能成本。

## 调整结果

| 募兵等级 | 旧基础 / 折算 | 新基础 / 折算 | 定价理由 |
| --- | ---: | ---: | --- |
| I级 | 10 / 10 | 10 / 10 | 仅为现役编制基线，`placeholder + baseline`，不消耗科研 |
| II级 | 500 / 1500 | 520 / 1560 | 对齐四级经济建筑解锁档 |
| III级 | 2200 / 9900 | 920 / 4140 | 对齐六级经济标准化档，消除单节点断崖 |

- 单条募兵建筑路线的高阶成本由 11400 降为 5700，下降 50%。
- 五条路线十项高阶科技由 57000 降为 28500，下降 28500。
- 二级相对旧值只提高 4%，三级下降约 58.2%；曲线由二级到三级的 6.6 倍跳跃收敛为约 2.65 倍。

## 五/六位面科研与人口复核

科研产能没有随本次降价调整。满配单个位面的固定科研设施为：三座三级研究所6点/秒、气象科研0.75点/秒、大学2点/秒、高能实验室2.5点/秒、位面观测阵列3点/秒，合计14.25原始点/秒；全局唯一跨位面中枢另提供4点/秒。

- 普通满配位面需要51个科研岗位；放置全局中枢的位面需要61个。
- 一座LV7房屋提供60人口，普通科研网络占其85%；中枢位面超过单栋容量，至少需要第二栋房屋。该占用尚未计入能源、农业、金币和军事岗位，因此科研极限只是理论上限，不代表混合经济常态。
- 本次仅重定价，不提高12点/秒全效阈值、20%超额效率或36点/秒有效上限，避免降价与提速叠加。
