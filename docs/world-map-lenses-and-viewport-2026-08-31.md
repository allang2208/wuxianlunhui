# 大地图图层、信息密度与视角记忆

2026-08-31，接续用户“继续优化”。本批只调整战略地图展示与镜头，不修改行军、寻路、战事、部队账本或切换基地协议。

## 操作与展示

- 底部“图层”提供总览、军事、基地、地形耗时四种模式。军事突出已知敌军、敌方据点及战事所在格，不推断攻击半径；基地突出己方建设基地与占领据点，不承诺当前可以入营。所有模式继续显示敌军、战事、我军、当前路线及悬停预览。
- 耗时图层读取原 `strategicTerrain` 与 `strategicStepDays`，按进入目标地格的成本覆盖银色，越强代表越慢。中景标倍率，近景标游戏小时；这不是现实时间或整条路线的总耗时。城市与兵棋所在格及当前跨越的两格让出成本标签，详细数值仍可从悬停面板查看。当前配置为遗迹14.4、沙漠15、森林16.8、雪地18、矿区21游戏小时/格，没有调快任何一方。
- 以实际地格投影尺寸决定信息密度：scale小于28时兵棋转为紧凑我/敌/守标记，保留控制/查看圈与状态徽记；28至48使用原军旗和简短地标；48以上在总览/基地模式展开有限宽度名称，军事模式追加行军/驻留等状态。悬停或选中地标在中景也可展开名称。建筑仍沿原锚点和随格缩放规则，未修改资产、旗帜姿态或相机55度投影。
- 缩小时的点击框跟随实际紧凑标记，不保留隐藏大旗的旧区域。建设基地标“基”，城市标“城”，据点标“据”，废墟标“墟”；战事另有虚线格框和“战”字，识别不只依赖颜色。

## 视角与本地偏好

- 关闭再打开保留地图中心、相对全图缩放、图层和六边格开关。页面正常退出时同样保存；独立键为 `wuxian_world_map_display_v1`，不进入战略存档、部队记录或经济账本。不承诺异常崩溃前尚未保存的最后拖动能恢复。
- 定位军团、地格、事件、位面和点击“全图”之前记录镜头位置，最多保留8步。右下“返回视角”按顺序返回；不改所选目标、不取消行军或撤销军令。连续拖动/滚轮不产生逐帧历史；没有历史时按钮禁用。
- 视角用地图坐标中心和相对缩放保存，不存画布像素。窗口变化时维持所看区域，按边界限制缩放与平移；为标题、图层说明与可换行工具栏预留显示空间，不把瞬时悬停卡片计入镜头布局。小面板允许放大到scale64以进入详细层级，不再只受全图4倍限制；正常最大scale135不变。极小窗口仍需实际体验确认。
- 旧/无偏好首次使用总览全图；无效中心与缩放不应用。无法访问localStorage时保留本次会话内存偏好；不同浏览器来源/固定EXE不共用这份UI偏好。不改固定EXE或它的存档。
- 控件最小44px，原键盘方向键、加减键、Home及面板Tab顺序保留；缩放按钮与百分比成组，窄屏换行时不拆散。地图显示偏好只在关闭或退出时写入，不跟随兵棋动画或世界每次更新写盘。

建议手动重点体验：

1. 有我军、敌军与围城时依次切换四种图层，核对兵棋/战事/路线仍可见，右键与固定指令栏结果一致。
2. 缩小再放大，在原大军旗外围和实际紧凑标记上分别点击，查看选择目标；同格多支兵棋和贴近城市时尤其留意遮挡。
3. 耗时模式悬停不同地形，对照标签、原单格耗时与路线预估；改令后当前已开始路段仍需走完。
4. 拖到边缘并缩放，定位军团/事件后点击返回；按Home后返回；关闭再打开、改变窗口大小及正常刷新后确认视角和开关恢复。返回镜头应不改变军令或选择对象。
5. 窄窗、低高度、键盘Tab和原减少动态效果设置下检查可读性。若仍拥挤，以用户实际尺寸反馈为下一轮范围，不能将本批静态接线等同运行时验收。
