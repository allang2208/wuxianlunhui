# 大地图：时间双显示、可关闭提示音与基地兵力

## 本批范围

在既有右键指令、途经点、入营回执基础上增加三项反馈。没有修改行军速度、地形权重、容量、敌军、围城、生产、出征资格、人口来源或存档协议。

## 操作入口与时间口径

- 地格悬停、目标详情、途经站累计时间、固定指令栏和当前路段统一显示“游戏时间 / 现实约需时间”。事件历史的世界时间仍是时间戳，不转换成剩余行程。
- 估算沿原 `strategicRouteEstimate`，已开始路段只计算剩余量；途经站与终点仍使用同一份估算，不新增路径计算或时钟。
- 现实耗时是原共享时钟毫秒按正常运行换算的持续运行时长，不是绝对抵达时间，也不承诺离线推进。暂停、后台挂起、接战和切场等待不包含在估算内；追击按敌军当前位置估算。
- 暂停或关闭 `animateSun` 时显示恢复/解冻说明，不用 UI 定时器推动行军。尚未调整整体行军节奏。

## 提示音

地图工具栏新增“提示音：开/关”和独立音量；默认开启、60%。使用 `wuxian_world_map_audio_v1` 保存展示偏好，不写入军团存档；存储不可用时保留本次会话设置。

所有素材复用项目现有运行时文件，没有新增下载、合成或加工音频：

| 类型 | 素材真源 | 本类音量 | 同类最短间隔 |
|---|---|---:|---:|
| 命令成功 | `audio-config.json#uiCues.buttonClick` → `assets/sounds/ui/button_click.mp3` | 0.8 | 180ms |
| 拒绝/受阻/目标失效/入营失败 | `uiCues.rightSidebarPanel` → `assets/sounds/ui/right_sidebar_panel.mp3` | 0.55 | 700ms |
| 抵达/入营完成 | `assets/sounds/ui/house_upgrade_complete.mp3` | 0.65 | 1500ms |
| 遇敌/新围城 | `assets/sounds/ui/knockdown_1.mp3` | 0.65 | 2200ms |

- 参数登记在 `data/audio-config.json#uiCues.worldMap`，最终音量为本类音量 × 大地图音量 × 主音量 × `ui` 声道音量。复用音色的听感尚待用户验收，不宣称为新生成的专属音效。
- 只从实际操作结果和新发生的战略事件触发；入营只在 `complete/failed` 状态变化时反馈，加载中不播完成音。打开面板、读档、阅读历史、标记已读和刷新剩余时间不补播。
- 普通命令不覆盖正在播放的威胁音；新威胁停止本模块的普通提示。重复提示直接限频，不积压补播队列。暂停、隐藏窗口、总静音和零音量时不触发新音效。
- 静音立即停止本模块持有的播放，音量滑块可调整正在播放的提示。`SoundManager.playFile` 仅在传入 `controllable` 时返回带播放令牌的控制柄，不能停止同文件后来被其他功能复用的音效；其余调用继续使用原池和原返回行为。
- 接管结果音的指令按钮通过 `data-ui-click-sound="off"` 跳过普通点击音，避免双响；其他按钮音效不受大地图开关影响。文字、徽记和事件记录始终保留，静音不隐藏警报。

## 基地兵力

在“位面”页选择建设基地，可查看驻留士兵、伤员/已知伤员、本次从此出征人数和当前可编组人数，并打开该世代最近一次归营回执。

- 当前现场：读取原 `getStrategicCandidates()` 的实际驻留士兵与生命值，并加入尚未物化的有效驻留记录；队友单列，不混入士兵人数。
- 后台基地：读取当前世代的建筑 `unitRoster/units` 及兵线驻留记录；不叠加 `troopLineDeployed`，因为那是原生产人口占用，不是当前驻留。
- 伤员、待落地人数是驻留人数的子集，不额外相加。调入途中的兵线记录单列，不提前显示为驻留。
- 建筑数量快照不含逐兵伤势，因此明确列出伤势未知人数，不能把“已知伤员0”解释成全员满血。后台建筑名册为最近结算状态，不新增高频后台推进。
- 可编组人数只来自当前实际候选；待落地士兵必须成功物化后才可选。观察模式、已有军团、没有有效指挥建筑、角色状态或入口不满足等情况显示原因；伤员继续遵循原有可选规则，不新增健康门槛。
- “本次从此出征”按军团出发基地与世代读取当前幸存士兵数；既不等于累计派出人数，也不按最初生产兵营归属重复记账。回执仍是历史批次，不是实时基地总兵力。
- 切场期间不读取半完成现场；旧世代快照不参与统计。新增方法纯读取，不调用出征打包、物化、归还、生产结算或兵线序列化。

## 文件

- `src/world/strategic-march.js`：双时间格式与时钟状态说明。
- `src/world/troop-line-system.js`：只读基地军力摘要。
- `src/world/world-strategy-journal.js`：新事件/入营状态变化的表现通知，监听异常不打断真实状态提交。
- `src/ui/world-map-audio.js`：提示音偏好、限频、播放控制与事件监听。
- `src/ui/sound-manager.js`：可选的单次播放控制柄、明确接管的按钮音跳过。
- `src/ui/world-switch-panel.js`：时间、音量控件、基地状态、原焦点与指令入口接线。
- `ui/panel-theme-backpack.css`：沿用冷钢主题，音量控件换行、44px操作区和两列兵力卡片。
- `data/audio-config.json`：上述复用音源与音量/间隔。
- `CHANGELOG.md`、`TODO.md`：进展与未实施的整体节奏边界。

## 交付边界与用户验收

只查看本次真实 diff 和实现必需的局部调用链，未运行测试或运行时验证，按约定由用户测试；未运行 lint、构建、服务器、浏览器/CDP、游戏或截图比对，未同步 EXE、提交或推送。

建议用户重点检查：

1. 同一目标在悬停、路线列表和固定栏显示一致的双时间；途中追加/截断包含当前路段剩余量，暂停后没有凭 UI 倒计时偷走进度。
2. 右键与指令按钮成功/拒绝只响一次；连续右键限频；声音开关和音量跨开关面板保持，主静音/界面声道静音均有效。
3. 已开始播放时关闭提示音或调零立即静音，其他界面音不被误停；重新打开或读取历史不补响。
4. 地图关闭时的新抵达、遇敌和围城仍能提示；入营失败不响完成音，重试成功才产生完成提示。
5. 出征前后原基地驻留减少、本次出征增加；归营目标基地人数增加且不与原生产人口占用重复，历史回执与实时总数区分清楚。
6. 后台基地的未知伤势、等待落地、观察视野和无指挥建筑提示准确；读档/基地重建后不串世代。
7. 窄屏工具栏可换行、地图定位避让工具栏；Tab能进入音量滑块，方向键调音量不移动地图，刷新不会丢失指令按钮焦点。
