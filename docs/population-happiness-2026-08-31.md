# 位面幸福度六项接入（2026-08-31）

已在本地工作区实现代码与界面接线。未运行测试、构建、lint、类型检查、浏览器或任何运行时验证，按约定由用户测试；未发布或更新固定EXE。核心运行时代码因共享依赖尚未合入而暂不发布，本文随知识档案归档，见 [Git交付边界](population-economy-publication-2026-08-31.md)。

“酒店”沿用项目现有的**三层酒馆（tavern）**，没有新建另一类建筑。酒馆和大商场（grand_mall）保持原来的每位面一座限制、岗位、费用、升级、产出与物流规则。

## 总体规则

- 每个位面独立保存幸福度，范围0～100，初始50。重建后的新位面世代从50开始，切场不会借用其他位面的分值。
- 与居民口粮共用每20秒结算边界。先按原规则处理到期人口变化与实际扣粮，再计算幸福度目标；幸福度每次最多向目标增加3点或减少6点，不会越过目标。
- 目标 = 限制在0～100内的（50 + 六项贡献之和）。六项贡献单位都是“幸福度点数”。
- 无居民时冻结分值，不积累娱乐/商业服务，不给空壳建筑加分；已有住房可沿原人口规则重新生成居民。
- 幸福度只影响居民增长周期。本轮不接税收、卫生、宗教、环境或政策实施效果；祭品仍为预留0%。

## 六项因素

| 因素 | 默认计分 | 数据依据 |
| --- | --- | --- |
| 食物保障 | 连续足粮1～2次+5；连续3次起+10；缺粮1～3次−5，4～6次−10，7次起−20 | 本位面仓库每20秒实际口粮支付结果；补粮须等下次足额结算才恢复 |
| 住房供给 | 入住率≤80%时+5；80%～100%时0；超额时−20×无房居民占总人口比例 | 实际人口与存活房屋容量；不是按房屋数量 |
| 住房品质 | 1～7级住房分别0/2/4/6/8/10/12，按实际入住人数加权 | 空房不加分，无房居民以0计入总人口分母 |
| 娱乐服务 | 0～+10 | 酒馆真实宴饮服务时长、岗位效率、人口效率与可服务人数 |
| 商业便利 | 0～+10 | 商场完成能源结算的营业时长、岗位效率、人口效率与范围内实际居民占比 |
| 安全感 | 连续和平120秒+5；本位面入侵/围城−10；核心生命低于50%额外−5 | 本位面、当前世代的战事与城镇核心；不看屏幕附近怪物数量 |

初次口粮结算前不发食物幸福加分；六项面板提示等待首次结算。分值与目标显示到小数点后一位，实际计算不先取整。

## 酒馆说明

满岗酒馆在“宴饮服务”阶段提供50人的娱乐名额；10个岗位，每人贡献10%，再乘实际人口效率。运输、等粮、无岗位不计服务；已送达的宴饮遵守原规则，断路后仍服务到本批结束。

本周期娱乐贡献 = 10 × 本周期平均有效覆盖比例。每段有效覆盖比例 = min(1, 当时有效娱乐名额 / 当时实际居民人口)。前台按服务剩余时间截取，后台读取原物流模拟真正产生的服务时间段，因此不能用结算末尾的“正在服务”状态冒充整期营业。

例如人口100、满岗且人口效率100%，整期宴饮贡献+5点；人口50、同样条件但只宴饮10/20秒，也贡献+5点。覆盖最多100%，该项最多+10点。无房居民仍可接受酒馆的全位面娱乐服务。

原酒馆最终产出倍率单独保留，幸福度不乘到酒馆生产倍率上，也不立即赠送人口。升级延长宴饮时间会通过真实营业时长影响幸福度，不直接硬加分。

## 商场说明

商业服务以实际成功结算的营业批次记账，不仅检查“建筑存在”或“仓库当前有能源”。保留原商场整数能源扣费和小数余数规则，不重复收取幸福度费用。

每个已营业批次的有效覆盖 = 范围内房屋实际居民 / 全位面实际人口 × 岗位效率 × 人口效率；以该批次的营业时长计入20秒周期平均，最多+10点。空房和无房居民不计覆盖。若出现重叠商场，按每栋房屋取较高服务量，不重复累加。

每名职员10%效率；初始6岗满编60%，升级到10岗才100%。例如覆盖50%居民、6岗满编、人口效率100%、整期营业，贡献+3点。扩建商场范围可增加实际居民覆盖，空房扩建不会加分。停业后已经完成的上一期贡献作为历史显示，本期剩余停业时段不再计入新服务。

## 与人口周期的关系

幸福修正 = (当前幸福度 − 50) × 0.8%，封顶±40%。

综合修正 = 食物修正 + 住房修正 + 幸福修正 + 祭品修正。

人口生成周期 = max(2秒, 20秒 × (1 − 综合修正))。

| 条件 | 综合修正 | 当前生成周期 |
| --- | ---: | ---: |
| 满房、足粮、幸福度50 | −80% +20% +0% = −60% | 32秒/人 |
| 满房、足粮、幸福度60 | −80% +20% +8% = −52% | 30.4秒/人 |
| 满房、足粮、幸福度40 | −80% +20% −8% = −68% | 33.6秒/人 |
| 未满房、足粮、幸福度60 | +20% +8% = +28% | 14.4秒/人 |

以上周期表示条件保持不变时的时长；中途幸福度改变会改变剩余倒计时，但不清空已经完成的进度。界面显示周期到两位小数，百分比到一位小数，倒计时仍向上取整到秒。

**满房继续增长，只减速。** 居民每人每20秒消耗3食物，口粮间隔不随幸福度改变。饥荒仅由食物自身恶化到−100%触发，每20秒流失1人；幸福度既不能凭空触发饥荒，也不能掩盖饥荒流失。
