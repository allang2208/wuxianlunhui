# 地牢随机事件金币平衡（2026-08-27）

## 结论

限定事件原本直接发放配置中的几十至数百金币，进入 C/B/A 后远低于同档一次战斗节点、Boss/通关奖励和同期产金建筑，金币分支会失去选择价值。本轮保留每个事件内部的高低价值关系，把配置值定义为“作者基础值”，按玩家实际进入的地牢等级统一缩放。

```text
限定事件最终金币 = round(事件基础金币 × dungeonRewards[实际地牢等级].eventGoldMultiplier)
```

正奖励和负金币结果使用同一倍率，避免赌博事件只放大奖励却不放大损失。倍率取实际地牢等级，不取事件元数据等级；同一事件通过“等级 ±1”进入相邻地牢时，会自动匹配当前阶段经济。

## 产金建筑参照

以下均读取当前权威配置，未计人口超额降效、经济工坊、酒馆、祭品等外部倍率。

| 阶段参照 | 建筑 | 当前基础/满配产金设计 |
| --- | --- | --- |
| 前期 | 银行 | `覆盖人口 × 每人每轮金币 × 职员数 ÷ 结算周期`；基础约每覆盖100人口1金币/秒，升级同时提高职员、每人口比例和结算速度 |
| 中期 | 皇家铸币局 | 基础2岗、7.5金币/人/10秒，约1.5金币/秒；满配4岗、15金币/人、约6.67秒一批，约9金币/秒，同时持续消耗能源与食物 |
| 中后期 | 大商场 | 每100覆盖人口基础约9.6金币/秒，满配约24金币/秒，同时消耗能源 |
| 后期 | 证券交易所 | 200人口、持有10万金币时约30.2金币/秒，随人口与资本增长 |
| 后期 | 算力重心 | 300人口、持有10万金币时基础6岗约38.58金币/秒；满员满升级约96.3金币/秒，同时持续消耗大量能源 |

以10分钟比较，单座后期建筑可产生约1.8万—5.8万金币。C/B/A事件的单次金币奖励因此提升到数百至约一千五百，但仍明显低于同期长时间建筑产出和完整地牢收益；事件的主要额外价值继续来自材料、恢复、路线揭示和临时增益。

## 边界

- 只调整事件金币；地牢怪物倍率、清剿奖、Boss奖、通关奖和产金建筑本身数值不改。
- 事件金币倍率只在结算时应用一次；界面结果显示的就是最终实际金币。
- 随机事件的药水、材料、强化石、改造券、魔尘、Buff、揭图和战斗分支均不受金币倍率影响。
- B/A雪原路线与五房竞技场基本生成配置已完成，但怪物和Boss仍使用黑狼占位，尚无正式生态与实测通关耗时；表中后期比较仍是基于正式奖励表和配置节点数的静态参考，待正式怪物/Boss入池后再用完整通关样本复核。
