# 经济建筑持续升级

> 发布边界（2026-08-31）：本文记录共享开发目录中的本地实现。此次Git仅归档市政厅素材/知识，相关基地、科技、治理UI及持续升级运行时代码仍待公共依赖合入；不表示已发布。详见 `docs/city-hall-closeout-2026-08-31.md`。

## 交互与规则

- 沿用出兵建筑“升级 / 持续升级”的双按钮、冷钢选中态与键盘焦点。经济卡片右侧将两个按钮纵排，保留名称、费用和读条空间。
- 默认关闭；点击“持续升级”立即尝试一次。金币、能源或科技暂不满足时保留目标，每秒重新调用原升级入口，卡片显示具体等待原因。关闭详情面板不影响运行。
- 同一 `cfgKey` 的建筑在前台与后台位面合计只允许一个持续目标，全部矿工营地也共用一个名额；研究所的塔楼、本栋模块和全局能力共用该限制。本栋经济升级等级与效果仍然独立，不会同步其他同类建筑。
- 同一队列正在升级时不能新挂目标；已有目标读条中可以停止，但不能直接切换到其他目标。停止后释放持续名额，另一栋可开启持续升级，原栋已付款读条仍继续完成。
- 点击“持续中”仅停止后续自动升级，已经扣费的当前读条继续完成。达到最高等级、项目失效、出售或被毁时清除目标。
- 每一档均重新读取当前等级与费用，开始时支付，读条完成后才应用效果；沿用科技解锁、跨位面费用、无限资源/瞬间升级等现有入口，不预扣未来费用。
- 保留原手动升级和独立队列：例如仓库扩建与仓储模块仍能手动分别进行；持续目标等待同一队列中的手动升级完成。多个建筑争用资源按现有实体更新顺序支付，不新增资源预留或优先级系统。

## 覆盖范围

矿工营地；房屋；仓库扩建与物流模块；研究所塔楼与本栋模块；天气塔；风车；银行；皇家铸币局；大商场；算力中心；经济工坊；位面谐振塔；军械库；战地医院；面包屋；连锁餐馆；奶酪/玉米农场；蒸汽/风力/光伏电站；守夜烛台。

出兵建筑共享/独立兵种模块、铁匠铺等全局能力、研究所全局研究及遗留兵营入口一并核对，统一使用同类互斥判定。市场、证券交易所、深钻井和高级科研设施当前没有升级卡片，本次不新增升级项目或数值。

有效升级卡均保留“升级 / 持续升级”操作位置，满级时禁用按钮并显示满级状态；已有持续目标始终允许点击停止。科技锁定卡片/按钮继续遵守原显示门禁，不提前显示未解锁内容；面板每秒检查门禁和同类占用状态，仅变化时重建按钮。

## 保存与离场

`economyContinuous` 只保存项目 ID，恢复时用当前配置排除失效/满级目标；旧存档缺少此字段时默认关闭。等待原因、轮询计时和 UI 刷新版本不入档。

主存档的升级等级、快照和位面世代全部恢复后，按位面键排序及建筑保存顺序保留同类首个有效持续目标；同栋同时存在全局/本地目标时保留全局目标。其余重复目标仅清除续升意图，不清除读条、不退费、不重复扣费。前台恢复排除自身位面快照，再查询其他已恢复建筑及后台位面，避免自锁；过期世代、被毁、满级及失效目标不占后台名额。

与现有出兵持续升级一致：离场后后台继续完成已经开始的一档，并保留目标；**后台不自动启动下一档，回到该位面后恢复续升**。本次没有改写后台支付调度。光伏电站补传原先遗漏的 `solarPowerModules/solarPowerUpgrade` 恢复字段，避免续升从丢失的等级或读条开始。

## 2026-08-30 代码审计与修复

范围为全部 `renderBuildingUpgradeCard` 的 29 处渲染入口：23 处本栋经济/烛台入口、6 处兵种/能力入口。入口按配置生成多张卡，数量不是实际卡片总数。已沿按钮事件、项目适配、原升级入口、实体更新、支付、完成效果、存档与后台占用核对；仅做代码审计，未运行自动化或游戏验证。

| 发现 | 修复 |
| --- | --- |
| 守夜烛台仅有手动按钮，支付逻辑在面板内 | 补充持续按钮；手动与自动共同调用 `CandleSanctuarySystem.startUpgrade`，照明完成效果不变 |
| 满级后操作区变为单段文字，按钮消失 | 本地与全局卡片都保留两个禁用按钮，活动目标可停止 |
| 经济目标按栋独立，全局目标只识别 `_continuous` | 两类目标共同占用同一建筑类别名额，按钮禁用与业务入口都执行互斥 |
| 研究所全局能力与本栋模块可以各挂一个目标 | 塔楼、模块、能力共用一个持续名额；已有手动独立队列保持原规则 |
| 旧档重复目标、后台满级/失效目标可能持续占名额 | 读档统一去重；后台查询及结算过滤/清理无效目标，不取消已付款读条 |
| 科技解锁或其他建筑释放名额后按钮可能仍保留禁用状态 | 面板打开期间每秒比对门禁与占用状态，变化时重建控件 |

新增的读档去重安排在 `WorldProgressionSystem.restore` 之后，避免使用上一局的位面世代筛选刚载入的快照。未修改建筑数值、碰撞/占地、招募、资源优先级或离场续升规则。以上是静态调用链结论，不代表运行时无冲突的保证。

## 用户验收重点

未运行测试或运行时验证，按约定由用户测试；未构建或同步固定 EXE。

1. 资源不足开启后补足资源、科技解锁后续升、关闭面板后续升。
2. 自动完成一档后正确读取下一档费用与效果，最高等级自动停止。
3. 同类两栋（含不同位面）只能开启一个持续目标；研究所全局/本栋项目不能同时开启。不同类建筑仍可各自持续升级。
4. 仓库扩建/模块独立手动升级、两种农场和两种新能源电站的分支。
5. 读条期间停止续升、转到另一栋开启续升，原栋本档正常完成且不再续费；满级双按钮与自动释放名额。
6. 存档重进、含重复目标的旧档、位面世代不同的存档切换、离场回场，以及光伏等级/读条恢复。
7. 烛台资源不足后续升、照明范围完成后变化、出售/被毁不再扣费；面板保持打开时科技解锁和互斥状态能更新。
