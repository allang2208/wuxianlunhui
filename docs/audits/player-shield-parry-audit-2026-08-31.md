# 玩家持盾、弹反与数值审计（2026-08-31）

本轮完成玩家盾牌相关代码审计、缺陷修复与挂载位置调整。只查看源代码、现有配置、源PNG和本轮真实diff；未运行测试或运行时验证，按约定由用户测试。未构建、启动游戏、同步EXE、提交或推送。

## 主要发现与处理

| 级别 | 原问题与证据 | 本轮处理 |
|---|---|---|

## 当前数值真源与公式

- 盾牌权威静态数据：`src/ui/equip-data-manager.js::SMALL_SHIELD_ITEM`；`data/equipment.json` 与 `public/data/equipment.json` 同步本轮小圆盾字段。旧物品继续走原 `completeWeaponFields`，不新增存档迁移。
- 技能：`data/skills.json::shieldDefense`，最高20级；两处既有技能兜底与配置的成长曲线相同，本轮不改等级、经验或成长率。
- 盾牌数值消费与展示：`src/config/shield-config.js::getShieldDefenseValues`。
- 原有防御公式：`src/combat/defense-formula.js::applyDefenseToDamage`，本轮从基类提取。以下公式是代码分析，不是实机测量。

设入参伤害为A，有效物防/魔防为D，持盾技能等级为L，强化等级为E：

```text
盾牌面板物防 = floor(15 + 1.5E)
当前副手持盾技能物防倍率 = 1 + 0.02L
  作用于包含盾牌在内的总物防，不只乘盾牌自身15点；不要求按住右键。
防御结算后伤害 = max(floor(A × (1 − D/(D+60))), floor(A × 0.10))
格挡承伤比例 = max(0.05, 0.50 − 0.02L)
格挡后伤害 = 防御结算后伤害 × 格挡承伤比例
近战弹反眩晕 = 1秒 + floor(L/5) × 0.25秒
```

物理D包含既有穿甲与腐蚀修正；魔法/电系用mdef及魔穿。没有攻击者data的环境伤害不套防御公式，既有毒/流血直接扣血路径也不改。玩家其余已有暴击、护手次级格挡、易伤、祭品、圣佑和墙垛等处理仍在原位置；最终扣血可受这些独立乘区及取整影响。

| 技能等级 | 当前持盾总物防加成 | 格挡承伤比例 | 对应额外格挡减伤 | 近战弹反眩晕 |
|---:|---:|---:|---:|---:|
| 1 | +2% | 48% | 52% | 1秒 |
| 5 | +10% | 40% | 60% | 1.25秒 |
| 10 | +20% | 30% | 70% | 1.5秒 |
| 15 | +30% | 20% | 80% | 1.75秒 |
| 20 | +40% | 10% | 90% | 2秒 |

这里“承伤10%”是防御结算后再保留10%，不是最终固定承受原伤害10%。例如A=100、有效D=60，防御结算为50，20级普通格挡为5（假设其他修正均为1）。防御本身的10%下限不阻止后续盾牌乘区继续降低伤害。

| 固定项 | 当前值与边界 |
|---|---|
| 举盾移动 | 正常步速×0.5；禁止冲刺与翻滚，停回体力 |
| 弹反时窗 | 每次有效举盾后1000ms；游戏暂停不流逝；窗内可反多次 |
| 弹反范围 | 朝向左右各120°，合计240°；背后120°扇区不能弹反，但仍可普通格挡 |
| 普通格挡 | 360°减伤，每次20体力，不按伤害大小增减 |
| 破防 | 受击时体力<20，清零并眩晕1500ms；这一次仍享受减伤，不授经验 |
| 刚好20体力 | 该次正常扣至0并获格挡经验；持续举盾下再受普通命中才破防 |
| 满体力200 | 无其他消耗、无弹反时连续正常格挡10次，第11次破防 |
| 恢复 | 收盾且其他动作许可后等待约500ms，再按120/秒×既有倍率恢复；0→200基础约2.17秒（含等待，受帧时钟影响） |
| 弹反成功 | 0伤害、0体力；近战施加眩晕/击退100，远程只抵消本次命中，不反射弹体 |
| 弹反免疫单位 | `_parryImmune` 仍免眩晕/击退/打断，玩家免伤免体力收益保留 |
| 经验 | 普通近战格挡2、远程格挡5、弹反10，弹反不叠格挡经验，满级不增长 |
| 1→20修炼 | 无额外经验修正时共19000经验，即1900次弹反或9500次近战格挡或3800次远程格挡 |
| 强化物防 | +0=15、+1=16、+2=18、+5=22、+10=30；单次强化有效增量交替1/2点 |
| 手枪组合 | 右键盾防、禁止ADS、仍可左键射击；既有副手盾换弹时间+50%不改 |

## 仍需注意的平衡与范围

1. **玩家承伤会明显下降。** 本轮补齐的是原有防御公式遗漏，影响玩家所有常规物理/魔法命中，不只盾牌。基类只是移入同一个公式函数，未改怪物公式或攻击力；仍需用户对照不同护甲、穿甲、腐蚀、魔法攻击检查结果。
2. **弹反仍很宽容。** 1秒、240°、窗内无限次、重举无冷却、零体力成本均保持。若希望更严格的操作门槛，应另行明确时窗/角度/冷却目标，本轮没有擅自削弱。
3. **普通格挡仍覆盖背面，破防当击仍减伤。** 这是现行规则，不把它们悄悄改成方向盾或全伤破防。
4. **远程弹反仍看来源实体当前位置。** 未改为投射物实际入射方向，也未改变爆炸/持续区域各自的isMelee与来源语义。未逐个重审全部怪物或重写通用命中附效管线。
5. 物防百分比影响全部物防，与满级90%格挡减伤叠加较强；这条成长曲线本轮只审计不重配。反制免疫、调试无敌仍能训练的既有顺序，以及每次受击重置/立即快照弹反结果的近期修复均保留。
