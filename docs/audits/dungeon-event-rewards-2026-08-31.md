# 地牢随机事件探索奖励审计与调整（2026-08-31）

> Git 整理说明：下文是共享开发工作区的历史实现记录，不代表本次分支包含全部代码；实际纳入与暂缓范围见[发布清单](audit-cleanup-and-publication-2026-08-31.md)。

本轮范围是随机事件节点：60个限定事件（废弃矿洞、僵尸、沼泽、雪原各15个）和5个通用事件。逐项读取成功、失败、无检定结果及实际发放路径；不把材料清单当成整个事件池，也不把静态核对当作运行验收。

限定事件共有330条结果定义，其中71条含材料奖励，52条调整了物品种类或数量。19条占位材料奖励已改配；原本只有金币、恢复、增益、路线或风险的分支保留，不强行追加物品。

正式材料用途：强化石用于装备强化；改造券用于装备改造；魔法粉尘用于附魔（当前卷轴费用有100、200、400档）。未增加新物品或配方，未改这些消耗。

**祭品边界**：真正的祭品及随机宝箱原有额外祭品掉落保持不变，包含可能与普通材料同名的祭品。本次移除的是按普通材料名称临时构造的占位物品。已在背包/仓库中的历史占位物品不自动替换或删除；未修改存档。

## 限定事件分级

以下是同级所有材料分支的单种数量范围，不代表每次同时给齐三种；实际组合见后表。限定事件按自身F–A级固定数量，选中相邻等级事件时不额外乘当前地牢等级。金币继续使用原有当前地牢等级倍率。

| 事件级别 | 强化石 | 改造券 | 魔法粉尘 |
| --- | ---: | ---: | ---: |
| F | 1 | 1 | 50 |
| E | 1 | 1 | 100 |
| D | 1–2 | 1 | 150–200 |
| C | 2 | 1–2 | 200–250 |
| B | 2–3 | 1–2 | 400–500 |
| A | 3–4 | 1–3 | 600–800 |

单材料分支和混合礼包不按同一数量机械翻倍：例如B级极光光晶保留2石+1券并恢复魔法；A级冰渔银链给3石+1券并保留金币；更苛刻的A级星辉锁匣给4石+2券并保留金币。已有治疗/防御增益的C级血清粉尘取200，同级材料与探路分支可取250。该方案是静态数值调整，实际产出节奏和经济影响仍需用户游玩验收。
