## 出征与退出的边界

- 出征仍先核对角色、场景、解锁、钥匙、世界目标及怪物资源登记；背包优先扣钥匙、仓库其次，开发免钥匙开关在真正提交时重新读取。
- 地牢初始化前先保留主城现场，然后明确标为地牢现场，避免初始化一半时回城把主城快照覆盖为残缺地牢。
- 世界探险记录延后至资源就绪才创建。失败前的已完成世界记录不被覆盖；地牢临时奖励 run 仅回收本次创建的记录，保留原邮件、回执与先前已结算 run。
- 本次进入尚未提交时不登记成功、失败或入侵进度；已经进入后发生资源故障，仍按原规则保留已得战利品、记录 failed，不授予通关资格。
- 死亡／放弃继续清空背包，包括背包里的金币；已装备物品、旧仓库和旧邮件不受影响。只修正了与实际行为冲突的代码注释，没有新增金币豁免。
- 普通安全撤离仍仅从起点入口触发；新增的异常返回不会变成任意房间可用的免费撤离。
- loading 先释放逻辑锁，再执行淡出；旧淡出回调不会隐藏新一轮回城重试的加载层。
- 未迁移已有占位材料或历史上限为1的粉尘堆，未修改存档格式；新模板修复不表示旧库存已自动整理。

## 交付与人工验收重点

已对照本轮修改前副本查看真实差异，并核对扣费、奖励投递、场景回滚、Buff读写及退出调用点。**未运行测试或运行时验证，按约定由用户测试；未运行lint、类型检查、构建、浏览器/CDP或游戏，未同步EXE。**

建议在新开地牢中重点验收：

1. 三张通关卡各领取一次，确认“附魔之礼”取得普通品质卷轴与200粉尘，能正常继续；连续点击不重复发奖。
2. 拾取战斗宝箱粉尘，确认新粉尘按9999上限堆叠；满背包时按原规则暂存，正常退出后再入仓／邮件。
3. 女神祝福与恶魔祈祷前后比较物攻、魔攻；女神祝福按场数消耗，恶魔祈祷图标持续到本局结束。
4. 背包／仓库钥匙、免钥匙、资源准备失败与目标变化：成功只扣一把，未提交失败不扣；回城后原地牢选择与有效世界目标保留。
5. 死亡、资源故障、放弃、安全撤离及正常通关，确认各自物品保留／损失口径；回城失败后重试不重复清包或结算，友军恢复，死亡返回位置正确。

这些是待用户执行的验收项，不是已执行或已通过的测试结果。当前固定EXE未更新，不能用旧固定版验收本轮改动。
